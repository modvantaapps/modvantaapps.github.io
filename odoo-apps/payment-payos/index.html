payOS Payment Gateway

VietQR payments with auto confirmation in Odoo 19, through payOS

View on Odoo Apps Store Ask about customisation
payOSVietQRbank transfer QRwebhookVietnamVND

What it does

Adds payOS as a payment provider in Odoo. The customer opens the payOS page, scans a VietQR code with a Vietnamese banking app, and Odoo confirms the order by itself when the transfer arrives.

Features

VietQR payment linkcreated for each payment, with an expiry you choose
Signed webhookthe signature is checked, then Odoo reads the link, so a partial transfer never marks the order as paid
Register Webhook buttonsaves the webhook on your payOS channel from Odoo
Check status and cancelfrom buttons on the transaction, and by a scheduled action when a webhook is lost
Partial transfersthe amount received is shown and the payment stays pending until it is complete
Buyer details and order linessent to payOS, without Vietnamese accents where banks need plain text
Two databases, one channelorder codes carry a checksum of the database, so a staging copy cannot collide with production
API logeach call and webhook, masked
Vietnamesethe module is translated
