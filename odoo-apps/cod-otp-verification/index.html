What it does

Confirm Cash on Delivery orders only after the shopper enters an OTP

Fake and impulse Cash on Delivery orders cost you a wasted delivery each. This add-on for Website Cash on Delivery adds an OTP step: after the shopper chooses COD and clicks Pay, a 6-digit code is sent to their phone, and the order is only confirmed once the right code is entered.

Codes can be sent through Twilio, MSG91, Fast2SMS, Textlocal, 2Factor or the WhatsApp Cloud API. A Demo mode posts the code in the order chatter so you can test the whole flow before connecting a gateway.
