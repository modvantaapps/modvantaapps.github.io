Odoo Clockify integration

Clockify Connector

Clockify time tracking lands in Odoo timesheets the moment a timer stops

View on Odoo Apps Store Ask a question

What it does

Connect a Clockify workspace to Odoo 19: time entries arrive as timesheet lines through webhooks, with project, task, employee and the billable flag. Projects and tasks go both ways, old entries come in by date range, and timers start and stop from the Odoo task.

Teams that track time in Clockify and invoice or report in Odoo copy hours by hand or export CSV files. This connector creates the Odoo timesheet line from each Clockify time entry, updates it when the entry changes and removes it when the entry is deleted.

Features

It is built for Clockify's limitsthe FREE plan allows 30 API requests per hour per workspace, so new time arrives by webhook (no polling), every API call is counted against a budget per workspace, and requests over the budget wait in a queue with their original times.
