BPMN Modeler

Draw BPMN 2.0 process diagrams inside Odoo, keep them in a process library with versions, link each step to the people, departments, documents and tasks behind it, and let everybody else view and comment without changing anything.

BPMN Modeler for Odoo 19

What it does

This app adds a BPMN 2.0 modeler to Odoo. You draw processes with the standard BPMN shapes (events, tasks, gateways, pools, lanes, sub processes, data objects and flows) directly in the browser, and every diagram is stored in a process library with an owner, a category, a status and numbered versions. Any element of a diagram can be linked to Odoo records - a user who is responsible, a department that owns a lane, a work instruction document or a project task - and anybody can comment on a single element. Diagrams are exchanged with other BPMN tools as standard .bpmn files and exported as SVG or PNG images. The modeler is built on the open source bpmn-js library from bpmn.io.

Who it is for

  • Quality and ISO teams writing procedures. Procedures are easier to audit when the drawing sits next to the people and documents behind each step. Each task or lane in a diagram can be linked to a responsible user, a department or a work instruction file, and old versions stay on record.
  • Operations managers mapping how work really flows. Draw the order-to-delivery or purchase approval process with standard BPMN 2.0 shapes, publish it, and let staff open it in a read-only viewer where they can comment on a single step.
  • Implementation consultants modelling a client's process. Diagrams import and export as standard .bpmn files, so a model drawn in another BPMN 2.0 tool can be opened in Odoo, and the result handed back as BPMN, SVG or PNG.
  • Companies sharing a process with suppliers or auditors. A read-only share link shows the diagram to someone outside Odoo. Links, comments and the chatter stay private, and the link can be replaced or switched off.

Setting it up

  1. Install the app. Administrators get the Administrator level automatically.
  2. In Settings > Users, give other users the Viewer or Editor level for BPMN processes.
  3. Add your own groupings under BPMN Processes > Configuration > Process Categories, and choose which kinds of records can be linked under Linkable Models.
  4. Go to BPMN Processes > Process Library and create a process, or use BPMN Processes > Import BPMN File to start from an existing .bpmn file.
  5. Draw the diagram, save, then click a task or lane to link records and add documentation in the side panel.
  6. Press Publish to save a version and make the process visible to viewers. Use Save Version before later changes.
  7. If outsiders need to see it, open the Share tab and press Enable Share Link.

BPMN Modeler: questions

Does it run the process as a workflow?

No. It's a modeler and viewer for documenting processes and linking them to Odoo records. Nothing in the diagram is executed.

Can I open files from other BPMN tools?

Yes, any BPMN 2.0 XML file that includes diagram layout. Files containing DOCTYPE or entity declarations are refused for security reasons.

What happens to links if I delete a step from the diagram?

Steps that have links or comments are kept and marked as removed from the diagram, so that information isn't lost. Steps without any are cleaned up.

Who can change a diagram?

Viewers see published processes and can comment. Editors can draw, link and save versions, and the Details tab lets you limit a process to named editors plus its owner. Administrators can do everything, including delete and configuration.

Which records can be linked to a step?

Users, contacts and attachments out of the box. Departments, employees, job positions, projects and tasks appear when those apps are installed, and administrators can add other models under Linkable Models.

Which Odoo edition does it need?

Community or Enterprise. It only depends on the Discuss (mail) module. The drawing uses the open-source bpmn-js library, whose licence requires the small bpmn.io logo to stay on the canvas.
