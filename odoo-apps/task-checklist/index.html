Project Task Checklist

Add checklist items to Odoo project tasks, fill them from reusable templates per project or per stage, show the progress on the kanban card, and stop a task being completed while mandatory items are still open.

View on Odoo Apps Store Ask a question

What it does

A task in Odoo has a description, but no list of steps the team can tick off. Teams end up typing checkboxes into the description, where nobody can see the progress, assign a step or check that the important ones were done.

This module adds a Checklist tab to the task with items that are ticked in one click, a counter and a progress bar. Items can be mandatory, assigned to a user, given a due date, or marked as customer items the customer ticks on the portal. Each tick is logged in the chatter with who did it.

Checklist templates add the same steps to every new task of a project, or to a task when it enters a stage. A project or stage can refuse to complete a task while mandatory items are open. Managers get a list of open items per user and checklist measures in the reporting.

Who it is for

  • Agencies and service teams with repeat delivery steps. A checklist template adds the same items, such as review, testing and handover, to every new task of a project. Each task form gets a Checklist tab with a counter, a progress bar and one-click ticks.
  • Teams with steps that must not be skipped. Mark items as Mandatory and turn on Checklist Required to Complete Tasks on the project. A task with open mandatory items is then refused when someone marks it done or moves it to a folded stage, and the error lists the items still open.
  • Projects that need sign-off from the customer. Items flagged as Customer Item can be ticked by a signed-in portal user on the task page when the project's Checklist on Portal is set to let the customer tick. The tick is recorded under the customer's name.
  • Project managers following up on open work. Tasks > My Checklist Items lists your open items and the unassigned items of tasks you work on. Reporting > Checklist Progress shows the done percentage and open items by project and stage.

Setting it up

  1. Install the module. It only needs the Project app.
  2. Create templates under Project > Configuration > Checklist Templates. For each item set Mandatory, Customer Item, Due After (days) and, if needed, Only Tickable By.
  3. Open a project, go to its Settings tab and, under Task checklists, choose the Default Checklists, Checklist Required to Complete Tasks and Checklist on Portal.
  4. To add a checklist when a task reaches a stage, edit the stage and fill Checklists Added in this Stage. Set its Checklist Rule to follow the project, always block, or never block.
  5. On any task, open the Checklist tab to tick items, type a new item and press Enter, drag items to reorder, or use Add checklist to pull in another template.
  6. Give the Override checklist rules right to the few people who may close a task with mandatory items still open. Each override is logged on the task.

Project Task Checklist: questions

Does this task checklist need Odoo Enterprise?

No. It depends only on Project, which is in Community.

Is each tick recorded?

Yes. An item keeps Done By and Done On, and the task chatter gets a Checklist updated note listing what was ticked, unticked or which mandatory items were removed.

If I change a template, do existing tasks change?

No. Template items are copied onto the task when it is applied. A template is only added once per task, so entering the same stage again adds nothing new.

Can anyone remove a mandatory item?

Not if it came from a template. Only a project administrator or a user with Override checklist rules can delete it or make it optional, and removals of mandatory items appear in the chatter.

Can an item be assigned to someone else?

Yes. Set the Assignee and a Due Date on the item. The assignee is added as a follower of the task and gets a notification listing the items assigned to them.

What doesn't it do?

Checklists live on project tasks only, not on other Odoo records. There are no scheduled reminders for overdue items, which are only highlighted and filterable. A customer can only tick through a signed-in portal account, not through a shared link.
