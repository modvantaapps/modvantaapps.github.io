Password Manager

Password Manager for Odoo 19 - Encrypted Team Password Vault

What it does

Keep the passwords your team shares inside Odoo instead of spreadsheets and chat messages: encrypted vaults per team, project or customer, roles for users and groups, reveal and copy on demand with a log of every access, a password generator, 2FA codes, rotation reminders and read-only sharing with customers on the portal.

Group credentials in vaults and give users or whole user groups a role: Read (see and reveal), Edit (add and change entries) or Manage (members, passphrase, key rotation, export, portal sharing). Single entries can be restricted further to named users or groups.

Passwords, 2FA seeds, secret notes and files are encrypted with AES-256-GCM under a random key per vault. The vault key is stored only wrapped by a server key taken from the Odoo configuration file, and each ciphertext is bound to its record and field.

Passwords are masked everywhere. Reveal shows a password for 30 seconds (configurable), Copy puts it on the clipboard without showing it. The value is fetched only at that moment and is never part of list or form data.

Every reveal, copy, 2FA code, file download, change, move, import, export, unlock attempt and portal view is logged with user or portal contact, time and IP address. Log lines cannot be edited or deleted; a retention period is optional.

Features

Give a sensitive vault an extra passphraseits key is wrapped a second time with a scrypt-derived key, so the database plus the server key are not enough to open it. Each user unlocks it for a set time; five wrong passphrases lock that user out for 15 minutes.
