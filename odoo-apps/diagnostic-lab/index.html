Diagnostic Lab Management

Run a diagnostic center, pathology lab or medical lab on Odoo: a test catalogue with reference ranges by age and sex, panels, patient registration, sample collection with barcode labels, home collection, lab results with out-of-range and critical flags, delta checks, two-person pathologist validation, a PDF lab report with QR verification, a patient portal, invoicing per payer and referring-doctor commission. One standalone module - no hospital system needed.

What it does

A critical value cannot be validated until the call to the doctor is logged with read-back. A big change against the patient's previous result needs a written pathologist review. The person who entered a result can never validate it, and validated results are locked - a reopened report logs every change. These checks run on the server, so no screen or import can bypass them.

Tests with parameters, units, decimals, methods, container, price and routine / STAT turnaround. 17 ready-made tests and 5 packages are installed (CBC, lipid profile, LFT, KFT, electrolytes, thyroid, urine routine and more) - edit or add your own.

Several ranges per parameter (male, female, child bands) with critical low and high limits. The range of the patient is frozen on the request, so later catalogue changes never rewrite old reports.

Formulas on parameter codes, e.g. LDL = CHOL - HDL - TG / 5 or MCV = HCT / RBC * 10, filled in as soon as the inputs are entered. Only arithmetic is allowed - no code runs.

Add a package to a request in one click; a test already on the request is never added twice, and the package price is spread over its tests for the invoice.
