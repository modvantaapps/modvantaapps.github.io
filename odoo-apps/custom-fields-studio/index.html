Custom Fields Studio

Add Custom Field to any model with no code: a Studio Community alternative. Global custom fields, dynamic fields and dynamic custom fields on form, list, search and kanban views, custom tab builder, field builder and field designer, required / readonly / invisible conditions, field groups, defaults, translations, import and export of custom fields any model.

View on Odoo Apps Store Ask about customisation

What it does

Custom Fields Studio lets an administrator add real database fields to contacts, sales orders, products, tasks, employees or any other business model, and place them on its form, list, search and kanban views from the user interface.

Choose a label and a type, say where the field goes - next to an existing field or in a new tab - and press Create / Update Field. The column is created, the views are regenerated and checked by Odoo itself, and your users see the field straight away. Search, filters, group by, import and export work like on any standard field.

There is no code, no formula and no server action to write: rules such as "required when", "read-only when" and "hidden when" are built from drop-downs, and the module turns them into safe view rules.
