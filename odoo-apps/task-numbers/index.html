Task Number

Call it OPS-042, not "the one about the invoice".

View on Odoo Apps Store Ask a question
What you getA number on every taskA series per projectFind it in one goScreens from a test databaseThe number sits on top of each cardA Number column in the listOpen a task by number from any screen

What it does

Odoo tasks only have a title and a database id, and nobody quotes either in a standup. This module gives every task a short number when it is created. Projects can have their own code, so the tasks of Operations become OPS-001, OPS-002 and so on, and your customers see the same number in their portal.
