POS Customer Restriction

Decide which customers each till can see, start every order with a walk-in customer, and never take an order without one.

View on Odoo Apps Store Ask about customisation
POS customer restrictionPOS own customerPOS default customerPOS mandatory customer

What it does

Three customer rules per point of sale. The server applies them, also to the customer search on the till.

Features

Only customers available in POStick 'Available in POS' on the customers a till may use (one by one or in bulk from the list). Everyone else is not loaded and not found by searching.
POS own customereach user sees only the customers where they are the salesperson or listed in 'Allowed POS Users'.
Customers with chosen tagsfor example only 'VIP Club' customers on the members' till.
POS managers see alloptional: POS managers keep the full list.
Created on the tilla customer created from the till is marked 'Available in POS' at once (and owned by the user in own-customer mode).
POS default customera walk-in customer is set on every new order; the cashier can still pick another one.
POS mandatory customerValidate asks for a customer first. The server refuses a paid order without one, so an old or offline till cannot slip through.
