Journal Restriction for Users

Choose which accounting journals each user can see and use

View on Odoo Apps Store Ask a question

What it does

Set the allowed journals of each accounting user. Everything else - journal entries, journal items, payments, bank statements and dashboard cards of the other journals - disappears for them, and they cannot post into those journals.

In Odoo every accounting user sees every journal of the company: the cashier of one shop sees the bank, a sales clerk sees the vendor bills. There is no setting to give someone only the journals they work with.

This module adds Allowed Journals on the user and, the other way round, User Access on the journal. A user with allowed journals only sees those journals, their entries and items, their payments and statements, and only their cards on the accounting dashboard. An empty list means no restriction.

The rule is enforced on the server with record rules, not just hidden in the menus, so it also holds for exports, reports and API access. Accounting administrators are never restricted.

Who it is for

  • Retailers with a cash journal per shop. Each shop manager records takings in their own cash journal and shouldn't see the head office bank account. Give them their shop's journals and the others drop out of their lists and dashboard.
  • Finance teams that split invoicing from purchasing. A clerk who only raises customer invoices can be limited to the Sales journal. If they try to open a new vendor bill, Odoo refuses it and tells them which journals they may use.
  • Companies that let an outside bookkeeper in. An external bookkeeper who handles the bank reconciliation can be given the bank journals and nothing else, including through exports and the API, since the limit is applied by record rules on the server.
  • Groups with branch accountants. Branch staff keep normal accounting rights but only for the journals of their branch, while the Accounting Administrators at head office still see every journal.

Features

Allowed journals on the user
Or users on the journal
Administrators see every journal
Restricted users see only theirs
Lists filtered on the server
Other journals are refused

Setting it up

  1. Install the module. It needs Invoicing or Accounting and the Analytic app, which comes with them.
  2. Go to Settings > Users & Companies > Users, open the accounting user you want to limit and open the Allowed Journals tab.
  3. Add the journals that person may see and use. Leave the list empty for anyone who should keep normal access.
  4. If you'd rather work from the journal side, open Accounting > Configuration > Journals, pick a journal and add users in its User Access tab.
  5. Ask the user to sign in again and check their Accounting dashboard. Only the cards of their allowed journals should show.

Journal Restriction for Users: questions

Is it just hiding menu items?

No. Global record rules filter journals, journal entries, journal items, payments, bank statements and statement lines, payment methods of journals, invoice analysis and analytic items of journal items. Lists, exports, reports and RPC calls all see the same restricted data.

What if I add journals to an Accounting Administrator?

Nothing changes for them. Administrators are never restricted, and the user form shows a note saying so when an administrator has allowed journals filled in.

Will reconciliation break for a restricted user?

It shouldn't. Exchange difference and cash basis entries go into company journals the user may not have, so the module creates those entries for them without opening the journals to them.

What happens when a restricted user creates a document?

New documents default to one of their own journals. If they have no journal of the needed type, for example no purchase journal for a vendor bill, Odoo stops them with a message naming the journals they may use and asking them to contact an administrator.

Do I need Enterprise?

No. It depends only on account and analytic, which are part of Community, and it also works on Enterprise. There's no settings page: the two lists on the user and the journal are all there is to configure.
