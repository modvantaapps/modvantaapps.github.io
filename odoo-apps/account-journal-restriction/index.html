Journal Restriction for Users

Choose which accounting journals each user can see and use

View on Odoo Apps Store Ask about customisation

What it does

Set the allowed journals of each accounting user. Everything else - journal entries, journal items, payments, bank statements and dashboard cards of the other journals - disappears for them, and they cannot post into those journals.

In Odoo every accounting user sees every journal of the company: the cashier of one shop sees the bank, a sales clerk sees the vendor bills. There is no setting to give someone only the journals they work with.

This module adds Allowed Journals on the user and, the other way round, User Access on the journal. A user with allowed journals only sees those journals, their entries and items, their payments and statements, and only their cards on the accounting dashboard. An empty list means no restriction.

The rule is enforced on the server with record rules, not just hidden in the menus, so it also holds for exports, reports and API access. Accounting administrators are never restricted.

Features

Allowed journals on the user
Or users on the journal
Administrators see every journal
Restricted users see only theirs
Lists filtered on the server
Other journals are refused
