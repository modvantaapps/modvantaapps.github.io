Contact Tags Automation & Auto-Segmentation

Automatically apply contact tags based on configurable rules, keeping CRM segmentation consistent without manual tagging. Auto tagging, contact tags, smart tags, CRM segmentation.

View on Odoo Apps Store Ask about customisation

What it does

Tags are the simplest way to segment contacts in Odoo, but only if everyone applies them the same way. In practice some contacts get tagged and many do not.

This module lets you define tag rules. Each rule has a target (company contacts, individuals, contacts with an email address, contacts in a specific country, or all contacts) and the tags to add. Active rules are applied to every new contact the moment it is created. A rule can also be run on all existing contacts, and all rules can be run on selected contacts from the contact list. Rules only add tags; they never remove tags you set by hand.
