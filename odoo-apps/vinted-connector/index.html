Vinted Connector

Vinted integration - Vinted marketplace connector for Odoo 19

View on Odoo Apps Store Ask a question
Sell on Vinted from your Odoo stock.

What it does

Turn Odoo products into Vinted listings, check them before they use a slot, and get every Vinted sale back as a sale order with the buyer address, the tracking code and the shipping label already on the delivery.

Paste the access token from the Vinted Pro Integrations Portal (the module splits it into the access key and the signing key) and press Test connection. Odoo reads the Vinted catalog tree, colors, sizes, package sizes and conditions, so you pick from real Vinted values instead of typing IDs.

Map each Odoo product category to a leaf Vinted catalog once, for example "Second-hand / Women" to Women / Clothing / Coats and jackets. "List on Vinted" on any product then makes a draft listing with title, description, price from your pricelist, brand, catalog, condition and package size filled in. The product photo is served from Odoo on a random link per listing, so Vinted can fetch it.

Validate sends the listings to the Vinted check without creating them, so a missing size or a short description shows up before a slot is used. Publish, send price changes, refresh the status and withdraw from the same list. When a product has no free stock left in the warehouse, its listing is withdrawn on the next run.

Every Vinted order becomes a sale order. When Vinted has made the label, the carrier, tracking code and the PDF label land on the delivery, ready to print. Cancelled orders cancel the sale order, returns open an activity for the salesperson.
