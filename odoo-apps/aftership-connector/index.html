AfterShip Integration

AfterShip Integration - AfterShip Tracking - Shipment Tracking Notifications

What it does

Every Odoo delivery tracked by AfterShip, whatever the courier.

Every tracked parcel with courier, order, delivery, customer, last event, expected date and status.

The AfterShip status and every checkpoint the courier reported.

Customers see the status and the expected date next to each delivery of their order.

A clean page with progress steps and the tracking history, no login needed (secure link).

Who it is for

  • Online stores shipping with many couriers. If parcels leave with UPS one day and a local courier the next, AfterShip tracks them all. Validating a delivery with a tracking number creates the AfterShip tracking, and status updates come back onto the delivery and the sales order.
  • Support teams tired of where-is-my-order emails. Customers get a tracking page and an order lookup page where they enter their order number and e-mail. Odoo can also e-mail them when a parcel is in transit, out for delivery, ready for pickup or delivered.
  • Warehouses that need to catch problem parcels. Failed delivery attempts and exceptions show up as Need Attention, and Odoo can schedule a to-do on the sales order for the salesperson or a user you choose.
  • Shippers already using AfterShip Shipping. An AfterShip Shipping carrier type gets live rates, prints labels in PDF or ZPL and cancels labels, using the courier accounts connected in AfterShip.

Setting it up

  1. Go to Inventory > AfterShip > Accounts and create an account. To try it without an AfterShip login, tick Demo Mode first.
  2. Paste the API Key from AfterShip admin > Settings > API keys and press Test Connection.
  3. Press Load All Couriers, then open each Odoo shipping method under Inventory > Configuration > Shipping Methods and set its AfterShip Courier.
  4. Copy the Webhook URL from the account into AfterShip's webhook settings and paste the Webhook Secret back into Odoo, keeping Verify Webhook Signature on.
  5. Check Track Validated Deliveries, Detect Courier and Refresh Every (hours), then tick which statuses e-mail the customer from Odoo.
  6. Validate an outgoing delivery with a tracking number and open Inventory > AfterShip > Shipment Tracking to see the new record and its checkpoints.

AfterShip Integration: questions

Do I need an AfterShip account?

Yes, for live tracking you need an AfterShip account and an API key. Demo mode answers locally in AfterShip's format without any calls, so you can test the flow first.

What if I can't set up the webhook?

Refresh by Schedule is on by default and updates open trackings every few hours (4 by default). Webhooks are faster, but the schedule covers you if a call is missed.

Is customer data sent to AfterShip?

Only the tracking details by default. Share Customer Contact with AfterShip is off unless you turn it on, which you'd only do if you want AfterShip to send its own notifications.

Which Odoo apps does it depend on?

Sales with stock (sale_stock), stock_delivery, Portal and Discuss mail. All are in Community, so Enterprise isn't required. Each AfterShip account belongs to one company.

How do customers find their tracking without logging in?

Each tracking has a public page secured with an access token, and the lookup page at /aftership/track finds a shipment only when both the order number (or tracking number) and the customer's e-mail match.

Can I see what went wrong on a failed call?

Yes. Inventory > AfterShip > Log stores each API call, webhook and notification with its request and response. Logs older than the Keep Logs (days) setting, 60 by default, are removed daily.
