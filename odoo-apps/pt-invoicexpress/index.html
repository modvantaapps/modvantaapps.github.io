InvoiceXpress Connector

Portuguese invoices must come from AT certified software. With this module you keep invoicing in Odoo: posting a customer invoice or credit note issues the legal document in InvoiceXpress, and the legal number, ATCUD, QR code and certified PDF come back to the invoice. Payments become InvoiceXpress receipts, debit notes go out as Notas de Debito, deliveries can issue transport documents and the SAF-T (PT) file is one click away. If someone cancels or settles a document directly in InvoiceXpress, the state check brings that back to Odoo.

Use the Debit Note button on a posted invoice for late interest or a price increase. With "Issue debit notes (ND)" on, the note is issued as an InvoiceXpress ND linked to the original FT, gets its own number and ATCUD, and the certified PDF is attached. A note on an invoice issued outside Odoo uses its reference (for example FT 2026/77).

Who it is for

  • Portuguese companies that invoice in Odoo. Invoices in Portugal have to come from AT certified software. Posting in Odoo issues the legal document in InvoiceXpress, and the legal number, ATCUD, QR code and certified PDF come back to the Odoo invoice.
  • Shops that issue simplified invoices or invoice-receipts. Each sales journal can be set to Fatura (FT), Fatura-Recibo (FR) or Fatura Simplificada (FS) with its own series, so a counter journal and a B2B journal can issue different document types.
  • Distributors that ship goods inside Portugal. Validating a delivery can issue a Guia de Remessa or Guia de Transporte through InvoiceXpress, with the AT code stored on the transfer.
  • Accountants who also work inside InvoiceXpress. With the state check on, documents cancelled or paid directly in InvoiceXpress are read back, so the Odoo side doesn't drift from the certified records.

Setting it up

  1. In InvoiceXpress, open Users > API and copy your account name and API key.
  2. In Odoo, go to Accounting > Configuration > InvoiceXpress > Account, set the environment, enter the Account name and API key, and click Test connection.
  3. Click Sync series and taxes so the series and tax names are read from your InvoiceXpress account.
  4. Open your sales journal, tick Issue with InvoiceXpress and choose the document type (FT, FR or FS) and the series.
  5. On every 0 % tax, set the IVA exemption code (M01 to M99). Set the InvoiceXpress tax name too if yours differs from IVA plus the rate.
  6. Back on the account, switch on the options you want: Send payments as receipts, Issue debit notes (ND), Read document states from InvoiceXpress and the transport document type.
  7. Post an invoice as usual, then check Accounting > Configuration > InvoiceXpress > Certified documents for the legal number and state.

InvoiceXpress Connector: questions

Does this make Odoo certified software in Portugal?

No. InvoiceXpress is the certified software that issues the legal documents. Odoo sends the invoice data and stores the number, ATCUD, hash and PDF that come back. Ask your accountant if you're unsure which documents your business must issue.

Can I cancel or reset a posted invoice?

A legal document can't go back to draft. Use Cancel on InvoiceXpress, give a reason, and the document is cancelled there and the Odoo entry is cancelled with it.

What if InvoiceXpress refuses a document?

The job is kept under Jobs with the error InvoiceXpress returned, for example a missing exemption code. Fix the cause and click Retry. Every API call is also kept in the API log with the API key masked.

Can I try the module before opening an InvoiceXpress account?

Yes. The Demo environment answers like InvoiceXpress from memory and makes no calls to the internet, so you can post test invoices and see the flow end to end.

How does the SAF-T (PT) export work?

Click Export SAF-T (PT) on the account and pick a month and year. The module asks InvoiceXpress to generate the file, so it covers the documents InvoiceXpress issued, not entries that never went through it.

Which Odoo apps and editions does it need?

It depends on Invoicing, Debit Notes and Inventory, so it runs on Community and Enterprise, on premise or Odoo.sh. Each company uses its own InvoiceXpress account, and a Portuguese translation is included.
