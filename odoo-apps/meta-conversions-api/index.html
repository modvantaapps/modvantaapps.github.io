Meta Conversions API and Meta Pixel

Meta Pixel and the Facebook Conversions API for your Odoo shop - purchases counted once, after consent

View on Odoo Apps Store Ask about customisation

What it does

The Meta Pixel tracks product views, searches, add to cart, checkout, payment and purchase on your Odoo website. The purchase is also sent from the server through the Conversions API with the same event ID, so Meta counts it once. Nothing loads before the visitor accepts the Odoo cookies bar.

This module puts the Meta Pixel on your Odoo website and sends the standard eCommerce events: ViewContent on a product, Search, AddToCart, InitiateCheckout, AddPaymentInfo and Purchase with the order number, value, currency and the products. Account creation, website forms and phone or email clicks can be tracked too.

With a Conversions API access token on the pixel, the purchase is also sent from the Odoo server (or every event, if you choose). The server event carries the same event ID as the browser event, so Meta deduplicates them, and it includes advanced matching data - email, phone, name, address and customer ID - hashed with SHA-256 in Odoo before it leaves.

The pixel waits for the Odoo cookies bar, can respect Limited Data Use, skips internal users and known bots, and supports several pixels per website. Every event is logged in Odoo with its payload and Meta's response, a debug panel shows the events on the page while you test, and a test event code sends server events to the Test events tab of Events Manager.
