Australia ABA File

Australia ABA File - Direct Entry Bank Payment File

What it does

Pay Australian suppliers from Odoo Community with one upload: pick the validated vendor payments, approve the batch and download the 120 character ABA (Cemtex direct entry) file your bank expects.

The module adds the ABA format to the Batch Payment module. A batch of vendor payments in an Australian company produces a real Cemtex direct entry file: a type 0 descriptive record with your bank abbreviation, user preferred name, APCA user ID and description, one type 1 detail record per payment with the supplier BSB, account, amount and lodgement reference, and a type 7 file total.

Every record is exactly 120 characters, blank padded and CRLF terminated. The BSB of each supplier and of your own account comes from the bank account records of the Australian localization. Fields that do not fit the format - for example a remitter name longer than 16 characters - stop the file with a clear message instead of being cut.

An optional self balancing transaction adds the matching debit record against your own account for banks that require a balanced file.
