ING WebPay Payment Gateway

Take ING Bank Romania card payments in Odoo 19, in RON and EUR, with pre-authorization and capture from Odoo

View on Odoo Apps Store Ask about customisation
ING WebPayING BankRomaniaPlata cu cardulRONEUR3D Secure

What it does

Adds ING WebPay, the online card payment service of ING Bank Romania, as a payment provider in Odoo. The customer pays on the ING page with 3D Secure 2. The ING guide documents no notification, so Odoo reads each result from ING, when the customer comes back and on a schedule.

Features

Hosted payment pagean order is registered for each transaction and the customer is sent to the ING page
RON and EUR on one providerING gives one API user per currency: enter both on the same provider
Result read from INGthe browser is never trusted: Odoo calls getOrderStatusExtended and compares the amount and currency
Pre-authorizationwith manual capture, Odoo uses registerPreAuth, then capture and void from Odoo (deposit and reverse)
Safe redirectthe customer is only sent to an ING address, for this order, and an order already registered is reused instead of duplicated
Customers who never come backa scheduled action reads open payments after the 10-minute session, once an hour, and cancels them after the time you set
Paid stays paida later reversal is logged for a person to look at, never applied by itself
Order number and emailoptional, to match the setting of your ING account
Point of Salewith Odoo online payment; ING requires no customer details, so an order with no customer can pay and nothing is invented
API logeach call, with the password and card details masked
Romanianthe module is translated
