Odoo DPD Shipping integration

DPD Shipping Integration

Ship with DPD from Odoo - one module for DPD in Western, Central and Eastern Europe and the Baltics

View on Odoo Apps Store Ask about customisation

What it does

A DPD connector for Odoo 19 that talks to the DPD API of your business unit: labels on validation, DPD Pickup parcelshops and lockers at the checkout, Predict notices, return labels, cash on delivery, courier pickup requests, the handover list and DPD tracking on every parcel.

DPD runs a different API in each country. The module adds DPD as a delivery method provider and lets each delivery method pick its business unit and API: DPD Netherlands and DPD Belgium (Shipper Webservice), DPD Germany (Web Connect and DPD Cloud), DPD France (with DPD Relais), DPD Poland (DPDServices), DPD Switzerland (Shivah Webservice), DPD Czech Republic (GeoAPI), DPD Hungary (DPD Shipping API), DPD Croatia and DPD Slovenia (EasyShip), DPD Romania (Web API with price calculation), DPD Lithuania, Latvia and Estonia (DPD Baltics API) and the Geopost META-API.

Each delivery method has its DPD product and services - Home / Predict, Classic / Business, Saturday delivery, age check, declared value - a fixed price or Odoo price rules, label format and return label rules. Validating the delivery order creates the parcels and attaches the label; a return label can come with every parcel.

Who it is for

  • Webshops in the Benelux and Germany. A shop that ships home deliveries with DPD Predict can print the label when it validates the delivery order, and let buyers send parcels to a DPD Pickup parcelshop or locker instead of their front door.
  • Sellers in Central and Eastern Europe. Merchants in Poland, the Czech Republic, Hungary, Croatia, Slovenia, Romania or the Baltics often sell on cash on delivery. The module books the COD amount on the parcel and can charge it automatically when a sales order isn't fully paid at shipping time.
  • Companies with more than one DPD contract. DPD runs a separate API in each country. If you ship from two warehouses in different countries, you create one delivery method per contract, each pointed at its own DPD business unit.
  • Warehouses printing many labels a day. Pick a batch of delivery orders, use the Actions menu and get every DPD label in a single PDF or ZPL file for the thermal printer.

Setting it up

  1. Install the module, then open Inventory > DPD > Delivery Methods (or Inventory > Configuration > Delivery Methods) and create a method with Provider set to DPD.
  2. On the DPD tab, choose the DPD Business Unit / API that matches your contract and fill in the account fields it asks for, such as DPD Login and DPD Password, the API token, or Master FID and Payer FID for Poland.
  3. Leave the method in the test environment first and press Test Connection. Demo Mode can be ticked if you just want to try the screens without any DPD account.
  4. Under Product and Services pick the DPD Product and Predict Notification, and tick Saturday Delivery, Age Check or Declare Value / Extra Insurance if your contract includes them.
  5. Under Labels set the label file (PDF or ZPL) and the PDF Paper size, and under Returns decide whether a return label is created with every parcel.
  6. Tick Deliver to DPD Pickup points on a pickup method so buyers can choose a parcelshop, then validate a delivery order to get the label attached to the transfer.
  7. Track parcels under Inventory > DPD > Parcels. A scheduled action updates tracking every two hours, and Handover Lists holds the courier pickups and protocols.

DPD Shipping Integration: questions

Do I need Odoo Enterprise?

No. The module depends on the standard Inventory delivery framework (stock_delivery) and Discuss, which are in Community. The checkout pickup point selector is used when Odoo's eCommerce app is installed.

Which DPD credentials do I need?

It depends on the country. Most business units need the API login and password DPD gives you, the Czech GeoAPI and DPD Hungary use an API key and customer number, the Baltics use an API token, and DPD Poland also needs the master and payer FID. Ask your DPD account manager for test credentials first.

Can I cancel a label after printing it?

Yes, as long as the parcel is still in the booked state. Once DPD has scanned it, Odoo refuses the cancellation. For DPD APIs that have no cancel call, the label is voided in Odoo with a note on the transfer, and DPD doesn't invoice unused labels.

Is there a sandbox?

Each delivery method can run against the DPD test system of its API, where labels aren't valid for shipping. There is also a demo mode that answers every call locally with sample labels, pickup points and tracking, so no network is involved.

Does it handle shipments outside the EU?

There is an International (non-EU) section on the delivery method for customs terms such as DAP or DDP and the export reason. Check the exact customs paperwork your destination needs with DPD, since the module only sends the data the API accepts.

Can Odoo book the courier for every country?

No. Courier pickup requests work for DPD Croatia, Slovenia, the Czech Republic, Hungary, Romania and the three Baltic countries. For the others the button tells you to book the pickup in the DPD portal.
