OpenCart Connector

OpenCart connector and OpenCart integration for Odoo: OpenCart order sync, OpenCart orders import, OpenCart product sync and OpenCart product export (options as variants), OpenCart stock sync, OpenCart customer import, OpenCart import of categories and manufacturers, specials to pricelists, taxes, coupons, status and tracking push, returns. OpenCart 4.x, OpenCart 4, OpenCart 3.x, OpenCart 3.0, OpenCart 3, multi-store OpenCart store, Open Cart bridge with a free signed OpenCart extension. Oversell guard, sync direction per entity, CRM opportunity per order, revenue report per store

View on Odoo Apps Store Ask about customisation

What it does

The OpenCart Odoo Connector links one or more OpenCart shops to Odoo. Products with categories, manufacturers, options and variants, customers and orders are imported; stock goes back to OpenCart, and order status changes in Odoo are pushed to the shop with a tracking comment.

Each OpenCart order status decides what happens in Odoo: import as quotation, import and confirm, or cancel. Payment and shipping methods, tax classes, stores and customer groups are mapped once, and OpenCart returns become Odoo credit notes.

A small extension for OpenCart 3.0.x and 4.x is included, with an optional real-time webhook. Demo stores let you try every screen before you connect your own shop.

Who it is for

  • OpenCart merchants moving the back office to Odoo. Keep selling on your OpenCart storefront while stock, delivery, invoicing and accounting run in Odoo. New orders come in as sales orders, and stock levels go back to the shop.
  • Owners of several OpenCart stores. One Odoo database can hold several OpenCart shops, on OpenCart 3.0 and 4.x side by side. Each store gets its own warehouse, sales team and pricelist.
  • Wholesalers with customer groups. OpenCart customer groups map to Odoo pricelists, and OpenCart specials and quantity discounts are imported as pricelist rules for those groups.
  • Shops that sell out of stock by accident. The oversell guard checks free quantity in the order's warehouse before an order is imported. It can hold the order as a flagged quotation with a to-do for someone, or refuse the import until stock arrives.

Setting it up

  1. In Odoo, open OpenCart > Configuration > Stores, create a store and press Download OpenCart Extension to get the file for your OpenCart version.
  2. In OpenCart, upload it under Extensions > Installer, install and enable Odoo Connector (Modvanta) under Extensions > Extensions > Modules.
  3. In OpenCart go to System > Users > API, enable an API user, copy the username and key, and add your Odoo server's public IP on the IP Addresses tab.
  4. Back on the Odoo store form, paste the shop URL, API username and API key and press Test Connection.
  5. Fill the Order Statuses, Payment & Shipping, Taxes and Stores & Groups tabs so each OpenCart status, method, tax class and customer group points at the right thing in Odoo. Create Missing Odoo Taxes helps with the tax step.
  6. Set what flows in which direction on the Sync Rules tab, then press Import Products, Import Customers and Import Orders, or use OpenCart > Synchronisation > Run a Sync.
  7. Scheduled actions then import new orders every 15 minutes and export stock every 30 minutes. Copy the Webhook URL and secret into the extension settings if you want orders in real time.

OpenCart Connector: questions

Do I have to install anything on my OpenCart site?

Yes. OpenCart's core has no full admin REST API, so the module ships a small free extension that adds one signed JSON endpoint. Each request is signed with HMAC-SHA256, has to come from an IP on the API user's list, and is rejected if it's older than five minutes or replayed.

Which OpenCart versions does it work with?

OpenCart 3.0.x and 4.0.2.x to 4.1.x. There's a separate extension package for 3.0 and for 4.x, both downloadable from the store form.

What happens to cancelled and returned orders?

You decide per OpenCart status on the Order Statuses tab: import as quotation, import and confirm, or cancel in Odoo. OpenCart returns are imported with their reason and status, and a credit note can be created from them.

Which Odoo apps does it need?

Sales, Inventory with delivery methods, and Invoicing, all available in Community. The CRM app is optional. If it's installed, you can open an opportunity per OpenCart order that's marked won or lost with the order.

Can I keep multiple currencies?

Yes. Orders keep their OpenCart currency and rate, or you can choose to import amounts in the company currency. The Revenue by Store report converts everything to company currency so stores in different currencies add up.

Can I try it without connecting a real shop?

Yes. Demo OpenCart 3 and 4 stores ship with the module and never call the network, so you can try the imports and the screens first.
