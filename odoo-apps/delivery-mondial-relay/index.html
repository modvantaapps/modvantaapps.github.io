Mondial Relay Shipping Integration

Ship with Mondial Relay from Odoo - Point Relais, labels, tracking and returns

View on Odoo Apps Store Ask about customisation

What it does

A Mondial Relay connector for Odoo 19: customers pick a Point Relais or locker on a map at the website checkout, validating the delivery order creates the Mondial Relay label, and the tracking history, return labels and a shipping dashboard live next to your transfers.

The module adds Mondial Relay as a delivery method provider in Odoo. It uses the public Mondial Relay web service for the Point Relais search, the postal code search and the parcel tracking, and the Mondial Relay shipment API (API V2) for the outbound and return labels.

Each delivery method is one Mondial Relay service: Point Relais / locker (24R), Point Relais XL (24L), home delivery (HOM, LD1, LDS) or D+1 (XOH). Prices come from a rate table by country and weight with delivery days, a fixed price or the Odoo price rules. Validating the delivery order books the shipment and attaches the label to the transfer.
