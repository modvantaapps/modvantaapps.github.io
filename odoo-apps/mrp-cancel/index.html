Cancel Manufacturing Order

Cancel a manufacturing order that is already done - stock comes back, and you see why when it cannot

View on Odoo Apps Store Ask a question

What it does

A Cancel Done Order button on done orders and a Cancel Manufacturing Orders action on the list. Finished products are taken back out of stock, components are returned, and every order is checked before anything changes.

Standard Odoo will not cancel a manufacturing order once it is done. When an order was produced by mistake - the wrong bill of materials, the wrong size, a duplicate - you are left with unbuild orders and manual stock corrections.

This module adds Cancel Done Order. The finished product is taken back out of stock, the components are returned to stock with reversal moves dated today, and the order becomes Cancelled with the reason, the user, the date and the method on the order and in its chatter.

Features

Cancel Done Order on a done manufacturing order
A reason, and a check before anything changes
The cancelled order keeps the full story
Reversal moves, history kept
Mass cancel from the list, each order checked
One result per order
Cancel and create a new draft order
The new draft order is linked
Find every order cancelled after it was done
Settings per company
