Batch Payment

Group validated vendor payments into one batch payment, have it approved, and export one bank payment file to upload to your bank - in Odoo Community, with an approval step and pluggable bank file formats.

What it does

Batch paymentVendor paymentsApprovalBank payment fileGeneric CSVOdoo Community

Odoo Community has no batch payment. This module adds one: select the vendor payments you want to pay, add them to a new or existing draft batch, and the batch keeps the bank journal, payment date, file format, total and one line per payment with the recipient bank account.

A batch goes Draft -> Approved -> Generated -> Sent. Preparing and approving are separate user groups, so the person who builds the batch does not have to be the one who releases it. The bank file can only be generated once the batch is approved, and the batch is frozen once it is marked as sent.

The generic CSV format is included. Country packs plug in their own file generator - for example the Australian ABA direct entry file - and appear in the File Format list.
