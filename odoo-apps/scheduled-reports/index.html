Scheduled Reports

Scheduled reports and reminders, emailed from any Odoo list

View on Odoo Apps Store Ask a question

What it does

Pick a model, filter the records with relative date periods, choose the columns, grouping and totals, and Odoo emails the list on your schedule - as a table in the mail body, an Excel file, a CSV file, a PDF table or the printed documents. Send one report to a team, or one reminder to each salesperson or customer with only their own records.

Odoo can show any list, pivot or graph on screen, but it cannot send it to anybody on a schedule: scheduled actions need Python code and the digest email only shows fixed figures. This module is a point-and-click report scheduler and reminder designer.

A scheduled report is a model, a filter, columns and a schedule. Reminders are the same thing aimed at people: records due in the next N days, sent to each responsible user or each partner, with a greeting you write.

Every send is logged with its recipients, the number of records and the exact files that went out.

Who it is for

  • Managers who want numbers in their inbox. A weekly list of last week's confirmed sales or overdue invoices can arrive every Monday at 8:00 as a table in the email, with Excel, CSV or PDF attached, without anyone logging in to export it.
  • Sales teams with one report per rep. With One report per responsible user, each salesperson gets an email holding only their own records, read with their own access rights if you choose Rights of each internal recipient.
  • Companies that chase deadlines. Reminders use the same builder to send records that fall in a coming period, for example contracts ending in the next 30 days or tasks due next week, to the people responsible for them.
  • Analysts who live in pivot views. Every pivot view gets a heatmap button that colours cells by value, and a button to email the pivot as Excel now or on a schedule, with the heatmap colours kept in the file.

Features

Pivot heatmap and email pivotcolour any pivot view by value from its toolbar, and email the pivot as Excel now or on a schedule.

Setting it up

  1. Open the Scheduled Reports app and go to Periodic Reports, or use New from Template to start from a ready-made report.
  2. Pick the Model, and optionally Start from a Favorite to copy the filter, grouping and sort of a saved view. Add Relative Periods such as Last 1 Months on a date field.
  3. Add Columns, set a Total (Sum, Average or Count) where useful, and choose Group By and Sort By.
  4. Under Formats, tick Table in email body, Excel (.xlsx), CSV or PDF table, and optionally Attach Document PDF to include the printed records.
  5. Add recipients as Users, Contacts or Other Emails, choose the Recipients Mode and the Data Restriction, and check the Run As user.
  6. Set the Frequency, days, Send at time and Timezone, then press Send Test to yourself before Send Now or waiting for the schedule.
  7. To colour pivot cells by your own rules, go to Configuration > Pivot Heatmap Colours and set a colour scale or expected range per measure.

Scheduled Reports: questions

Can a recipient see records they normally can't access?

Only as far as the Run As user can. Records are read with that user's access rights and record rules, and a non-manager can only set themselves as Run As. With Rights of each internal recipient, every internal user gets just what they're allowed to see.

What happens when there's nothing to report?

With Do not send when empty ticked (the default), the run is logged as Skipped and no email goes out.

Can I check what was sent last month?

Yes. The Send Log records each run with its trigger (schedule, Send Now or test), recipients, record count, the email status and the files that were attached.

Which Odoo edition does it need?

It only depends on the mail module, so it runs on Community and Enterprise and works with any model you have installed.

Who can create reports?

There are two access levels: User: Own Reports, who see and edit their own schedules, and Manager. Purging the send log is reserved for administrators.

Are links in the email safe to send to customers?

Links to records are only added for recipients who are internal users. External contacts get the data without links into Odoo.
