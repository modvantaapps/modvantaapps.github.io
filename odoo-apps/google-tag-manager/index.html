Google Tag Manager (GTM) eCommerce dataLayer

Google Tag Manager for Odoo eCommerce - a clean GA4 ecommerce dataLayer on every page

View on Odoo Apps Store Ask about customisation

What it does

Load your GTM container on every page of the Odoo website and push GA4 ecommerce events with full items to the dataLayer - from product lists to the purchase, once per order - with server-side tagging, hashed user data and Google Consent Mode v2 on the Odoo cookies bar.

Enter your container ID and the module loads Google Tag Manager on every page. It pushes GA4-named events to the dataLayer: view_item_list, select_item, search, view_item, add_to_cart, remove_from_cart, add_to_wishlist, view_cart, begin_checkout, add_shipping_info, add_payment_info, purchase, login, sign_up and generate_lead, plus odoo.page on every page. Items carry id, name, price and quantity, and the purchase is pushed once per order.

The container can load from your own domain through a tagging server URL and tag serving path (server-side tagging), and Tag Manager environment parameters can be set for staging websites. Optionally a hashed user ID and user-provided data on purchase are added for enhanced conversions, and Odoo's own Google Analytics tag can be replaced.

Google Consent Mode v2 follows the Odoo cookies bar in basic or advanced mode with default states per consent type. A debug mode writes every push to a panel on the page, and an event log in Odoo keeps the pushed events with value, currency, consent and page.
