POS Extra Charges

Service charge, carry bags, takeaway packing and delivery charges on POS orders - added by rule, kept up to date, checked by the server.

View on Odoo Apps Store Ask about customisation
POS service chargePOS bag chargesPacking chargeDelivery charge

What it does

Each charge is a rule. The till keeps one line per charge up to date while the order changes, and the server checks mandatory charges again when the order is paid.

Features

POS service chargea percentage of the untaxed order or a fixed amount, automatic on Dine in orders (or on every order).
Cashier can change itoptional: the Charges button opens a number pad with the default value, for one order.
POS bag chargescarry bags (small, large...) added with the Charges button; each tap adds one more bag.
Packing chargean amount per item for takeaway, only for the POS categories you choose, with a maximum.
Delivery chargea fixed charge on Delivery orders, free above an order amount, with an optional minimum order.
Linked feesa bottle deposit or eco fee on a product: one consolidated line with the right quantity.
Server checka mandatory charge that is missing or changed by hand is refused when the order is paid.
Own product per chargetaxes, income account and receipt name come from the charge product; charge products stay off the product screen.
ReportReporting -> Extra Charges: charges collected per rule and month.
