POS Keyboard Shortcuts

Keyboard shortcuts for every POS screen - search and add products, customer, quantity, discount, price, payment, payment methods, validate and print - with the key shown on each button and an F1 help overlay. Every key can be changed per point of sale.

View on Odoo Apps Store Ask about customisation

What it does

On a counter with a keyboard, reaching for the mouse or the touch screen for every product, payment method and validation slows the queue down. Standard Odoo POS has almost no keyboard shortcuts.

This module adds shortcuts to every screen of the POS: the product screen (search, add the first product shown, customer, quantity, discount and price modes, payment, notes, order lines, new and held orders, refund), the payment screen (payment methods, invoice, validate), the receipt screen (print, new order) and the orders and customer lists. Small key hints on the buttons show which key does what, and F1 opens the list of shortcuts of the screen you are on.

Features

Shortcuts are records per point of salechange a key, switch one off, add a key that picks a given payment method or adds a given product. Keys the browser keeps for itself, such as Ctrl+W, are refused with the reason. While the cursor is in a text field only function keys and Ctrl or Alt combinations run, and barcode scans never trigger a shortcut.
