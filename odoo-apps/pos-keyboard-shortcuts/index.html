POS Keyboard Shortcuts

Keyboard shortcuts for every POS screen - search and add products, customer, quantity, discount, price, payment, payment methods, validate and print - with the key shown on each button and an F1 help overlay. Every key can be changed per point of sale.

View on Odoo Apps Store Ask a question

What it does

On a counter with a keyboard, reaching for the mouse or the touch screen for every product, payment method and validation slows the queue down. Standard Odoo POS has almost no keyboard shortcuts.

This module adds shortcuts to every screen of the POS: the product screen (search, add the first product shown, customer, quantity, discount and price modes, payment, notes, order lines, new and held orders, refund), the payment screen (payment methods, invoice, validate), the receipt screen (print, new order) and the orders and customer lists. Small key hints on the buttons show which key does what, and F1 opens the list of shortcuts of the screen you are on.

Who it is for

  • Busy checkout lanes. Supermarket and pharmacy cashiers who work all day at a keyboard can go to payment with F9, pick a payment method with Alt+1 to Alt+9 and print with Ctrl+P, without reaching for the mouse.
  • Shops with barcode scanners. A scanner types characters very fast, and a careless hotkey setup can swallow them. Combinations a scanner could produce are kept away from shortcuts, so scanning still adds the product.
  • Restaurants on desktop terminals. Where the restaurant features are active, the floor plan has its own shortcuts and Alt+T jumps back to the tables from any screen.
  • Chains with different till layouts. Each point of sale keeps its own list of key combinations, so the express counter and the service desk can be set up differently.

Features

Shortcuts are records per point of salechange a key, switch one off, add a key that picks a given payment method or adds a given product. Keys the browser keeps for itself, such as Ctrl+W, are refused with the reason. While the cursor is in a text field only function keys and Ctrl or Alt combinations run, and barcode scans never trigger a shortcut.

Setting it up

  1. Install the module. Every existing point of sale gets the default shortcut set straight away.
  2. Go to Point of Sale > Configuration > Settings, pick the register and find Keyboard Shortcuts. Turn the feature on or off, choose Key hints on buttons, and choose what happens While typing in a field.
  3. Click Edit Shortcuts, or open Point of Sale > Configuration > Keyboard Shortcuts, to see each action with its screen and key.
  4. Change a key by typing a combination such as Alt+K or F6. Browser, system, clipboard and numpad combinations are refused with the reason.
  5. Switch off a shortcut you don't want instead of deleting it, and use Reset to Default to bring back the standard set for that register.
  6. Open the register and press F1 to see the help overlay listing every shortcut that works on the current screen.

POS Keyboard Shortcuts: questions

Can a shortcut skip manager approval or access rights?

No. A shortcut presses the same button the cashier would click on screen. If another app asks for a manager PIN or hides the button for that user, the shortcut follows the same rule.

Why can't I assign Ctrl+W or F5?

Combinations the browser or operating system use, like closing a tab, reloading or switching windows, are blocked. So are copy and paste keys, the keys the POS numpad already uses, and Ctrl+Alt combinations, because on many keyboards that is AltGr and it types characters.

Does it slow the till down or need the server?

No. The shortcuts load with the POS data when the session opens, and key presses are handled in the browser, so they keep working while the register is offline.

What happens when the cursor is in the search box?

That depends on the While typing in a field setting. By default, Ctrl, Alt and function key shortcuts still run while plain letters are typed into the field. You can also choose to run no shortcut at all while typing.

Which Odoo apps does it need?

Only Point of Sale, which is in Community. Shortcuts for the floor plan, global discount or cashier lock are only created when those POS features are switched on.

Does it work with POS UI Tools?

Yes. When both are installed, F2 is left to the numpad show and hide key of POS UI Tools, and product search moves to Shift+F2.
