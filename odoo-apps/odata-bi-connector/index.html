Odoo Excel Connector and Power BI Connector

Odoo Excel Connector and Power BI Connector: live Odoo data in Excel, Power BI and other BI tools

View on Odoo Apps Store Ask about customisation

What it does

Open any list in Odoo, filter it, and pick Live Excel Link from the gear menu: you get an .odc file that opens in Excel as a table you can refresh. Or choose a model, its columns and a filter yourself, and publish it as an OData v4 entity set that Power BI Desktop and Excel read with Get Data > OData feed. CSV, JSON and HTML feeds serve Google Sheets and scripts. Each access token runs as an Odoo user, so record rules apply.

The BI Connector publishes datasets from Odoo. A dataset is a model, a list of columns (including related fields one level deep), a record filter, a row limit and page size, and either one line per record or grouped totals such as revenue per month and salesperson. Each published dataset is an entity set of an OData v4 service, with a $metadata document, and a CSV, JSON and HTML feed.

Power BI Desktop and Excel connect with the OData feed URL shown on the Connect tab and Basic authentication with an access token as password. The service supports $select, $filter, $orderby, $top, $skip and $count, with server-side paging. Google Sheets reads the CSV feed with IMPORTDATA.

Access tokens are created per integration, run as a chosen Odoo user and can be limited to some datasets, an expiry date and IP addresses. The secret is shown once and only a hash is stored. Every call is written to a usage log with the token, dataset, kind of request, rows returned and duration.

Who it is for

  • Finance teams that report in Excel. If someone exports the same invoice or receivables list to Excel every Monday, a Live Excel Link turns that list view into a feed, and Data > Refresh All brings in the current rows without another export.
  • Companies building Power BI dashboards on Odoo. Power BI reads the OData v4 feed through Get Data > OData feed. With Publish Relations on, it also sees how tables link, for example invoice lines to products.
  • Small teams that live in Google Sheets. A CSV feed URL works with IMPORTDATA, so a shared sheet can show stock on hand or the sales pipeline straight from Odoo.
  • IT admins who must control outside access. Each access token runs as one Odoo user and only reads the datasets it was given. You can add an IP allow-list, an expiry date and a rate limit, and revoke it at any time.

Setting it up

  1. Open the BI Connector app and go to Datasets. Start from Dataset Templates, or create a dataset, pick the Model, choose the Columns and set a Record Filter.
  2. Choose Rows (one line per record) or Aggregated (grouped totals) as the mode, then click Publish.
  3. Go to BI Connector > Access Tokens, create a token, set Runs As to the Odoo user whose rights should apply, add the Allowed Datasets and click Generate Secret. Copy the secret, as it's only shown once.
  4. Optionally fill Allowed IPs, Expires On and Requests per Minute on the token.
  5. In Power BI or Excel, use Get Data > OData feed with the URL from the dataset's Connect tab. Choose Basic authentication, enter token as the user name and paste the secret as the password.
  6. For a one-off sheet, open any list view in Odoo, filter it, open the gear menu, choose Live Excel Link and download the .odc or .iqy file.
  7. Adjust the OData max page size, CSV / JSON max rows and Keep usage logs (days) under BI Connector > Configuration > Settings.

Odoo Excel Connector and Power BI Connector: questions

Can a token see data its user can't?

No. Every query runs as the user set in Runs As, so that user's access rights and record rules apply. The token also only reads the datasets listed on it.

Do I need an Excel add-in or a Power BI gateway plugin?

No add-in is needed. The .odc file and the OData feed use Power Query, which is built into Excel for Windows. Excel asks for the token once, and later refreshes reuse it.

Which OData query options work?

$select, $filter, $orderby, $top, $skip and $count, with paging through @odata.nextLink, /$count and single rows by key. $expand is available for many-to-one relations when Publish Relations is switched on for the dataset.

How does it cope with very large tables?

OData results are paged, 1,000 rows per page by default. CSV and JSON feeds can be streamed chunk by chunk with Stream CSV / JSON Feeds or stream=1 in the URL, and aggregated datasets can cache their totals for a few minutes.

What happens when I regenerate or revoke a token?

The old secret stops working straight away for every report that used it. Only a hash of the secret is stored, so it can't be shown again. Paste the new one in your BI tool's data source settings to reconnect.

Which Odoo apps does it need?

It depends only on base, web and mail, so it works on Community and Enterprise. A dataset template only shows up if the app it reads from, such as Sales or Inventory, is installed.
