Power BI and Excel Connector

A live OData feed of your Odoo data for Power BI, Excel and other BI tools - with tokens, record rules and a usage log

View on Odoo Apps Store Ask about customisation

What it does

Choose a model, its columns and a filter, and publish it as an OData v4 entity set that Power BI Desktop and Excel read with Get Data > OData feed. CSV, JSON and HTML feeds serve Google Sheets and scripts. Each access token runs as an Odoo user, so record rules apply.

The BI Connector publishes datasets from Odoo. A dataset is a model, a list of columns (including related fields one level deep), a record filter, a row limit and page size, and either one line per record or grouped totals such as revenue per month and salesperson. Each published dataset is an entity set of an OData v4 service, with a $metadata document, and a CSV, JSON and HTML feed.

Power BI Desktop and Excel connect with the OData feed URL shown on the Connect tab and Basic authentication with an access token as password. The service supports $select, $filter, $orderby, $top, $skip and $count, with server-side paging. Google Sheets reads the CSV feed with IMPORTDATA.

Access tokens are created per integration, run as a chosen Odoo user and can be limited to some datasets, an expiry date and IP addresses. The secret is shown once and only a hash is stored. Every call is written to a usage log with the token, dataset, kind of request, rows returned and duration.
