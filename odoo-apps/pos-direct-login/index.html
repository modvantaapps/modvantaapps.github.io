POS Direct Login

Cashiers log in and land on the till. Idle tills lock themselves. PINs change without a manager.

View on Odoo Apps Store Ask about customisation
POS direct loginPOS auto lockPOS QR loginPOS PIN reset

What it does

Four things a shop asks for every day at the till, in one small module, checked by the server.

Features

Direct logina user set to 'Open POS at Login' lands on that point of sale right after login. The session is opened or resumed by Odoo, no menu clicks.
POS only userstick 'POS Only (No Backend)' and every backend link sends the user back to the till. Administrators are never blocked.
Log out when leaving the POSthe Backend button and Close Register log the cashier out, so the next person starts on a clean login page.
Auto lock when idleafter the delay you choose (seconds), the till returns to the employee login screen. A card payment waiting for a terminal is never interrupted.
Change PIN on the login screenthe cashier picks their name, types the current PIN and the new one twice. The server checks the current PIN, digits only, minimum length, not one digit repeated, and that no other cashier of the register has it.
Brute force guardfive wrong current PINs in 15 minutes block PIN changes for that employee.
Manager PIN resetReset POS PIN on the employee form suggests a random 6-digit PIN. The PIN is never written in the chatter.
QR badgeprint an employee QR badge from the Badge ID; the camera button on the POS login screen scans it.
POS PIN Logevery change, reset, wrong PIN and block, with who, when and on which till. Nobody can edit or delete a row.
