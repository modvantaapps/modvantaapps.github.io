Odoo Estafeta Shipping integration

Estafeta Shipping Integration

Ship across Mexico with Estafeta straight from Odoo: live Estafeta rates on quotations, the waybill (guia) and its PDF label when you validate a delivery order, one waybill per parcel, delivery to an Estafeta office (Ocurre), pickup requests (recoleccion) with their folio and tracking that updates itself.

What it does

Mexican shops and warehouses with an Estafeta contract that are tired of typing every guia into the Estafeta portal. Estafeta becomes a normal Odoo delivery method: use it on quotations and delivery orders, next to your other carriers.

Enter the API key, client secret, subscriber ID, 7-digit customer number and sales organization from your Estafeta contract, then Test Connection. Choose the service ID (for example 70 Terrestre or 60 Dia Siguiente), the printing template, a default box, declared value (insurance) and the return document. Demo mode lets you try everything without an account.

Prices come from the Estafeta Cotizador REST API or from the Frecuencia Cotizador web service, for the service you sell (Terrestre, Dia Siguiente...), with or without IVA, split by parcel when you set a maximum weight. When Estafeta only delivers a postal code at an office (Ocurre forzoso), the salesperson sees a warning. Fixed prices and Odoo price rules work too.

A scheduled action asks Estafeta for the status of open shipments (20 tracking codes per call) and stores each event with its date and place. The status bar moves from waybill created to delivered, the delivery order gets a note on every change and the Track on Estafeta button opens the public tracking page.

Each Odoo package becomes its own Estafeta waybill with its weight and dimensions, and all labels are merged into a single PDF. Delivery to an Estafeta office (Ocurre) is sent with the office code you chose on the sales order or the delivery order.

Who it is for

  • Mexican online shops. A store selling across Mexico can show the real Estafeta price on the quotation and get the guia and its PDF label the moment the delivery order is validated, instead of retyping every address into the Estafeta portal.
  • Warehouses shipping several boxes per order. Each Odoo package becomes its own Estafeta waybill with its own weight and dimensions, and the labels come back merged into one PDF so the packer prints once.
  • Businesses whose customers collect at an office. Some buyers prefer to pick up at an Estafeta office (Ocurre), and some postal codes are only served that way. You keep a list of the offices you use and pick one on the sales order or the delivery order.
  • Teams that book daily collections. If Estafeta collects from your warehouse, you can request the recoleccion from the selected delivery orders or have it sent automatically on validation, and the folio is stored on each order.

Features

Validate the delivery orderEstafeta returns the guia and the 10-digit tracking code, the PDF label is attached and posted in the chatter, and the tracking code becomes the tracking reference. The sender address is the warehouse; colonia, exterior and interior number are sent in the Estafeta address format.

Setting it up

  1. Go to Inventory > Configuration > Delivery Methods, create a new method and set Provider to Estafeta.
  2. On the Estafeta tab, fill in the Account group: Estafeta API Key, Estafeta Client Secret, Subscriber ID, the 7-digit Customer Number and the Sales Organization from your contract.
  3. Press Test Connection while the method is still on the test endpoints. Tick Estafeta Demo Mode instead if you don't have credentials yet.
  4. Under Waybill enter the Service ID of the service you sell (for example 70 for Terrestre), the Estafeta Default Package and whether to Declare Value (Insurance).
  5. Under Prices choose Estafeta Price: the Cotizador REST API, the Frecuencia Cotizador SOAP service, a fixed price or Odoo price rules, and set whether the quoted amount includes IVA.
  6. Under Offices and Pickup tick Delivery to Estafeta Office (Ocurre) and Request Pickup on Validation if you want them, then add your offices under Inventory > Estafeta > Offices.
  7. Validate a delivery order to get the waybill. Shipments, Pickups and the API Log are all under Inventory > Estafeta.

Estafeta Shipping Integration: questions

Can I ship outside Mexico with it?

No. The module checks every address and stops with an error when the country isn't Mexico. It also asks for a 5-digit postal code, a street and a city before it sends anything.

What happens if I cancel a guia?

Estafeta doesn't publish a cancellation call, so the waybill is marked cancelled in Odoo, draft pickups for it are removed and the shipping cost on the transfer is reset. A note on the delivery order reminds you not to hand over parcels with those labels and to ask your Estafeta executive about prepaid waybills.

Does it support cash on delivery?

No. The Estafeta label service the module uses has no cash on delivery option.

I have different API keys for rates, pickups and tracking. Is that a problem?

No. There's a Separate Keys per Service section on the delivery method where an administrator can enter a dedicated key and secret for the Cotizador, pickups and tracking. If you leave them empty, the main key is used.

Do I need Odoo Enterprise?

No. It depends only on the Inventory delivery framework and Discuss, both in Community, and needs no extra Python library.

Is it available in Spanish?

Yes. A Spanish translation of the screens and messages ships with the module, so a warehouse team in Mexico can work with Odoo set to Spanish.
