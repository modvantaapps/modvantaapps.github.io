Odoo Looker Studio integration

Odoo Looker Studio Connector

Looker connector for Odoo: Google Looker Studio dashboard on live Odoo data, Looker Studio integration with a Google Data Studio community connector, BI connector with secure data feed, embed Looker Studio report in Odoo, business intelligence

View on Odoo Apps Store Ask a question

What it does

The Looker Studio Odoo Connector lets you build Looker Studio (Google Data Studio) dashboards on live Odoo data. You choose which tables and columns leave Odoo by putting them in a dataset; Looker Studio reads only those, with the access rights of the Odoo user you pick.

Odoo generates the Apps Script code and manifest of your own private community connector, step by step. Without a script, every table is also available as a CSV or JSON feed URL protected by a token.

Ready-made datasets for Sales, Invoicing, Inventory, CRM, Point of Sale, Purchase and Contacts get you started in one click, and a date table makes time-based charts easy.

Who it is for

  • Owners and managers who report in Looker Studio. Sales orders, invoices, stock on hand, CRM leads, POS orders and purchases can be charted in Looker Studio straight from Odoo. The Sample Datasets wizard creates ready tables for the apps you have installed.
  • Analysts who need clean tables. A table reads one Odoo model with a filter and the columns you pick. You can follow relations with a dot, rename columns, add formula columns and set each one as a dimension or a metric.
  • Admins who decide what leaves Odoo. Looker Studio only sees the tables placed in a dataset, read with the rights of the dataset's Run As user. Feed tokens can be limited to some datasets or tables, to some formats, to IP addresses and to a number of requests per minute.
  • Teams that want the report inside Odoo. Paste a Looker Studio embed URL under Looker Studio > Reports, choose which user groups may see it, and press Add To Menu to give it its own menu entry.

Setting it up

  1. Install the module and open the Looker Studio app. Users who build datasets and tokens need the Administrator role of Looker Studio Connector in the user settings.
  2. Go to Looker Studio > Configuration > Sample Datasets and press Create Datasets, or create your own dataset under Looker Studio > Datasets. Set Run As to a reporting user with read-only rights.
  3. Open a table, use Add Columns to pick fields, and set the Date Range Field (for example date_order) if the Looker Studio date control should filter it. Check the Preview tab and press Add Date Table on the dataset if you want a calendar table.
  4. On the dataset press New Feed Token, keep Connector API ticked and copy the token. It is shown once.
  5. Press Connect Looker Studio. Odoo fills in the Code.gs and appsscript.json tabs and lists the steps to paste them into a new project at script.google.com and deploy it.
  6. Open the deployment link in Looker Studio, authorise the script, enter your Odoo address as Path and the token as Key, then pick the dataset and table and press Connect.
  7. For small tables you can skip the script. The Without A Script tab explains a Google Sheets IMPORTDATA bridge and a one-off CSV upload made with Download CSV For Upload.

Odoo Looker Studio Connector: questions

Does it need Odoo Enterprise?

No. It only depends on the base, mail and web modules, so it runs on Odoo 19 Community and Enterprise. The sample datasets appear for the apps that are installed.

How does Looker Studio get access to Odoo?

Through a feed token sent by the connector script in the Authorization header. Odoo stores only a SHA-256 hash of it, so it can't be shown again. You can regenerate or revoke a token, give it an expiry date and an IP allow-list, and every request is written to the Access Log.

Which data can a token read?

Only the datasets on the token, and only some of their tables if you fill Only These Tables. Rows are read as the dataset's Run As user with its record rules, never as the public user or the superuser. Odoo technical models, key and password fields and binary fields can't be added to a table at all.

Is this a connector from the Looker Studio gallery?

No. Odoo generates the code of your own private community connector, and you deploy it in your Google account with Apps Script. Your data goes from your Odoo to your Looker Studio and nowhere else.

Can I use it without Apps Script?

Yes. Every table has a CSV URL and a JSON URL. With a token that has Allow Token In URL and CSV ticked, a Google Sheet can load the CSV with IMPORTDATA and Looker Studio can read that sheet.

What doesn't it do?

It never writes to Odoo, and one Looker Studio data source reads one table, so you combine tables with a blend in Looker Studio. Odoo must be reachable over https on a public address for Google to call it. Google's own Apps Script and connector quotas still apply, and the plain CSV and JSON feeds send date-times in UTC.
