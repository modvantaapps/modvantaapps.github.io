Odoo Looker Studio Connector

Looker connector for Odoo: Google Looker Studio dashboard on live Odoo data, Looker Studio integration with a Google Data Studio community connector, BI connector with secure data feed, embed Looker Studio report in Odoo, business intelligence

View on Odoo Apps Store Ask about customisation

What it does

The Looker Studio Odoo Connector lets you build Looker Studio (Google Data Studio) dashboards on live Odoo data. You choose which tables and columns leave Odoo by putting them in a dataset; Looker Studio reads only those, with the access rights of the Odoo user you pick.

Odoo generates the Apps Script code and manifest of your own private community connector, step by step. Without a script, every table is also available as a CSV or JSON feed URL protected by a token.

Ready-made datasets for Sales, Invoicing, Inventory, CRM, Point of Sale, Purchase and Contacts get you started in one click, and a date table makes time-based charts easy.
