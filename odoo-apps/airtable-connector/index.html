Odoo Airtable integration

Airtable Connector

Keep an Airtable table and an Odoo model in step: contacts, products, leads or your own records, one way or both ways

View on Odoo Apps Store Ask about customisation
AirtableTwo-way syncField mappingUpsertSigned webhooks5 requests per second

What it does

Paste an Airtable personal access token, load your bases, and pick a table for an Odoo model. The connector proposes the field mapping from matching names, then imports rows into Odoo, sends Odoo records to Airtable, or does both. A match key (an email or a reference) stops duplicates on either side. Register a webhook and Airtable tells Odoo when rows change; the scheduler covers the rest every 15 minutes. It never sends more than 5 requests per second to a base, which is the limit Airtable sets.

Features

Bases, tables and fieldsread from Airtable with the token; reload the fields when the table changes
Any Odoo modelcontacts, products, CRM leads, projects, your own models; one sync per model and table
Field mappingproposed from names and labels; text, numbers, money, dates, checkboxes, selections, many2one and many2many fields
DirectionOdoo to Airtable, Airtable to Odoo or both, and per field when one side owns it
Match key and upsertexisting rows are found by the match field; on export Airtable updates the row instead of adding a second one
Conflict rulewhen a record changed on both sides since the last sync, Airtable wins or Odoo wins
Filtersan Odoo domain for what is sent, an Airtable formula for what is imported
Webhooksregistered from Odoo; each ping must carry a valid X-Airtable-Content-MAC signature, then the changed rows are read from Airtable; webhooks are refreshed before they expire
Rate limitat most 5 requests per second per base, a 30 second pause after a 429, batches of 10 records
Rows deleted in Airtablekeep the Odoo record, archive it, or only drop the link
Runs as a chosen userevery read and write uses that user's access rights, also when the scheduler runs
Sync logrecords sent, created, updated, unchanged and failed, with the error text
