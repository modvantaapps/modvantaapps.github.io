CinetPay Payment Gateway

CinetPay for Odoo 19: mobile money payments in West and Central Africa - Orange Money, MTN, Moov Money and Wave - with status checks, secure notifications and refunds by transfer.

What it does

A CinetPay payment provider for Odoo eCommerce and portal payments, built on the CinetPay API v1. Odoo opens the CinetPay payment page, the customer pays with mobile money, and Odoo confirms the payment with the CinetPay status before validating the order.

Who it is for

  • Online shops in francophone West Africa. A webshop in Abidjan, Dakar or Bamako sells in XOF and most buyers pay by phone. The CinetPay page lets them pay with Orange Money, MTN, Moov Money or Wave, and Odoo confirms the order only after it has read the final status from CinetPay.
  • Companies selling in more than one CinetPay country. CinetPay issues separate API credentials per country. You add each country account to the same provider, and Odoo uses the account for the customer's country, or the one matching the order currency.
  • Businesses collecting invoices through the portal. Customers can pay a sales order or an invoice from the Odoo customer portal using mobile money, so there's no need to send a separate payment request by phone.
  • Merchants who sometimes need to refund. CinetPay has no refund endpoint. When refunds by transfer are switched on, Odoo sends the amount back as a CinetPay transfer to the mobile money number that paid, and records the transfer fee.

Features

Mobile money methodsthe module adds four payment methods: CinetPay (the customer picks on the CinetPay page), Orange Money, Wave and Moov Money. MTN Mobile Money uses Odoo's own Mobile Money method, which is sent to CinetPay as the MTN operator of the customer's country. When the customer picks an operator in Odoo, it is sent to CinetPay for the customer's country. Other operators, such as Free Money, are not separate methods; you can pick them as the operator for a refund transfer.
One CinetPay account per countryCinetPay issues an API key and API password per country. Add Cote d'Ivoire, Senegal, Cameroon, Mali, Burkina Faso, Togo, Benin, Guinea, DR Congo or Niger; Odoo uses the account of the customer's country, or the one for the order currency.
Secure notificationsthe notification is accepted only when its notify_token matches the one CinetPay gave for that payment; Odoo then reads the final status from CinetPay before confirming the order.
Status checkson the return from CinetPay, from the transaction form, and every 15 minutes for payments still waiting.
Refunds by mobile money transferCinetPay has no refund endpoint, so Odoo sends the refund as a CinetPay transfer to the number that paid, from your CinetPay balance. Full or partial, with the transfer fee recorded.
Sandbox and productionsk_test_ keys use the CinetPay sandbox in Test Mode, sk_live_ keys go to production; Odoo refuses keys of the wrong mode. Test Connection shows each account's balance.

Setting it up

  1. Go to Accounting > Configuration > Payment Providers (or Website > Configuration > Payment Providers) and open CinetPay.
  2. In the credentials area, add one line per country: pick the Country and paste the API Key and API Password from your CinetPay merchant panel, then press Check to verify them and see the balance.
  3. Use sk_test_ keys with the provider in Test Mode and sk_live_ keys when it's enabled for production. Odoo refuses keys that don't match the mode.
  4. In CinetPay Checkout, choose the Payment Channel (Push, OTP code or QR code), the page language and the Payment Label shown on the CinetPay page, and tick the refund-by-transfer option if you want refunds sent back by mobile money.
  5. On the Payment Methods tab, keep CinetPay and the operators your customers use, such as Orange Money, Wave or Moov Money.
  6. Press Test Connection, then publish the provider. The Notification URL shown on the form is sent to CinetPay with every payment, so you don't have to enter it anywhere.

CinetPay Payment Gateway: questions

Does it need Odoo Enterprise or the eCommerce app?

No. It depends only on Odoo's Payment module, which is in Community. It works on the eCommerce checkout if you have it, and on portal payments of sales orders and invoices.

Which currencies and countries are covered?

XOF, XAF, GNF, CDF and USD, in whole amounts between 100 and 2,500,000. Country accounts can be added for Cote d'Ivoire, Senegal, Cameroon, Mali, Burkina Faso, Togo, Benin, Guinea, DR Congo and Niger.

How does Odoo know a payment really went through?

A notification is accepted only if its notify token matches the one CinetPay issued for that payment. Even then, Odoo asks CinetPay for the status before it confirms the order. If a notification never arrives, a scheduled action checks waiting payments every 15 minutes, and you can press Check CinetPay Status on the transaction.

What happens when a customer abandons or the payment fails?

CinetPay statuses are mapped to Odoo states: expired payments are cancelled, failed ones go to error with the reason, and initiated or pending ones stay open until the next status check.

How are refunds paid?

As a CinetPay transfer from your CinetPay balance to the payer's number, full or partial. The number and operator are taken from the payment, and Refund Details lets you correct them before refunding. Transfers are limited to between 100 and 1,500,000 per refund.

Is the payment page translated?

The module ships a French translation, and you can set the CinetPay page language to follow the customer, or force French or English.
