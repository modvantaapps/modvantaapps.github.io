GDPR Data Request Portal

Answer every GDPR data request on time, from one place

View on Odoo Apps Store Ask about customisation

What it does

Customers file access, portability, rectification and erasure requests from My Account or a public form. You get a request list with deadlines, a one-click data export and an erasure that anonymises the contact while your invoices stay intact.

Under GDPR a person can ask what data you hold about them, ask for a copy, ask you to correct it or ask you to erase it, and you have one month to answer. In standard Odoo these requests arrive by email and nothing tracks them.

This module adds a Privacy & My Data page to the customer portal and a public privacy request form for people without an account. Every request gets a reference, a channel, an Answer Before date and a handler. Public requests only start once the requester clicks the confirmation link sent to their email address.

From the request you generate the data export (a JSON file and a printable HTML report) built from a Personal Data Register you can edit, preview what an erasure would do, and then apply it: the contact's identifying fields are replaced by a placeholder and the contact is archived, never deleted, so accounting documents keep working. Every step is written to the chatter.
