QuickBooks Payments Gateway

Take QuickBooks Payments on your Odoo 19 website, invoices and payment links

View on Odoo Apps Store Ask about customisation

What it does

Connect your QuickBooks Payments account with OAuth and take card payments in Odoo. The browser exchanges the card for a one-time token directly with Intuit, as Intuit documents, and only the token reaches the Odoo server. For US-based QuickBooks Online companies.

Features

Card tokensThe form on the Odoo page sends the card to the Intuit Tokens API from the browser; the server only sees the token.
OAuth connectionConnect to QuickBooks from the provider form. The refresh token is stored encrypted, the access token stays in memory only, as the Intuit security rules ask.
Authorization and captureWith Capture Amount Manually, authorize and then capture or void from Odoo.
RefundsFull or partial refunds from Odoo.
Saved cardsCards are stored with QuickBooks Payments from a one-time token, and deleted there when removed from Odoo.
reCAPTCHAIntuit requires a reCAPTCHA on payment pages: payments are checked with the reCAPTCHA of Odoo as soon as its keys are set.
ResultsAuthorization code, masked card, AVS and security code results are kept on the transaction.
API logEvery call is logged with tokens and card data masked.
