Odoo BigQuery Connector

Load your Odoo data into Google BigQuery - incremental, scheduled, and ready for Looker Studio, Power BI or Tableau

View on Odoo Apps Store Ask about customisation

What it does

Pick ready-made datasets for Sales, Invoicing, Inventory, Contacts and more, or build your own tables from any Odoo model. The connector creates the BigQuery datasets and tables, sends only new and changed rows, and checks that the row counts match.

The BigQuery connector turns Odoo into a source for your data warehouse. Each BigQuery dataset in Odoo holds tables, and each table is fed from an Odoo model with the columns you choose - plain fields, related values or formulas - and a filter. Tables sync incrementally (insert new rows and update changed ones) or by full refresh, on a schedule or on demand.

Sample datasets for the installed apps - Contacts, Sales, Invoicing, Inventory, CRM, Point of Sale, Purchase - are created in one step, with a date table and example views. Rows are read as a chosen Run As user, so Odoo access rights decide what leaves the system. A dashboard compares rows in Odoo with rows in BigQuery per table, and every run is logged with rows sent, inserted, updated and deleted, and the cost.
