User Audit Log

See who changed what in Odoo, with the value before and after

View on Odoo Apps Store Ask about customisation

What it does

An audit trail for any model: creations, changes and deletions with before and after values, the content of deleted records, successful and failed logins with the IP address, and a hash chain that shows whether anyone altered the log. Plus session management: active sessions, force logout, session timeout, session limits and login notification on a new device.

Odoo's chatter only tracks a few fields on a few models, and when a record is deleted its history goes with it. When a price, a bank account or a user's access rights change, there is often no way to tell who did it, when, or what the value was before.

This module records events on the models you choose with audit rules: who created, changed or deleted a record, when, from where (web client, server code, external API, import or scheduled job), from which IP address, and the value of each changed field before and after. A deleted record keeps the values of its fields in the log. Logins, failed logins and logouts are recorded too.

Every entry is sealed into a hash chain. Verify Integrity re-computes the chain and reports whether any entry was changed or removed. Secret values such as passwords and API keys are stored as hidden. A dashboard and a history of each record from its Action menu make the log easy to use.
