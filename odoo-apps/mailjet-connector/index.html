Odoo Mailjet integration

Mailjet Connector

Connect Odoo to Mailjet: send Odoo emails through Mailjet, keep mailing lists in sync both ways, create and send Mailjet campaigns from Odoo mailings, and get opens, clicks, bounces, spam complaints and unsubscribes back into Odoo by webhook and statistics import.

Who it is for

  • Companies that already pay for Mailjet. If Mailjet already handles your newsletters, you can keep it for delivery and campaigns while Odoo stays the place where contacts and mailing lists are maintained.
  • B2B sellers sending quotes and invoices by email. Route Odoo's outgoing mail through Mailjet so quotations, invoices and chatter messages leave from a validated sender, and see bounces come back on the message in the chatter.
  • Hosts that block SMTP ports. Some cloud servers don't allow outbound SMTP. The Send API option delivers Odoo's email to Mailjet over HTTPS instead, so you don't need an open SMTP port.
  • Marketing teams that report in Odoo. Build a list and a mailing in Odoo, have Mailjet send it, then read opens, clicks, bounces, spam complaints and unsubscribes on the mailing without logging into Mailjet.

Features

Transactional emailone click creates an Odoo outgoing mail server for the Mailjet SMTP relay (in-v3.mailjet.com) or for the Mailjet Send API v3.1 over HTTPS. Quotations, invoices, chatter notifications and Odoo mailings then go out through Mailjet, each tagged with the Odoo Message-ID so Mailjet events come back to the right message.
Mailing listspush an Odoo mailing list to Mailjet (subscribed contacts are added, opted-out and blacklisted ones are unsubscribed), pull a Mailjet list into Odoo (new contacts are created, Mailjet unsubscribes become opt-outs), import all your Mailjet lists, and keep chosen lists in sync every hour. Selected Odoo contacts can be sent to a Mailjet list from the contacts list.
Campaignschoose a Mailjet account on an Odoo mailing to create the Mailjet campaign draft with your subject, sender and HTML, send a Mailjet test, then send it now or at the scheduled date. Mailjet statistics (sent, opened, clicked, bounced, blocked, spam, unsubscribed) are imported every 3 hours or on demand, with open, click and bounce rates.

Setting it up

  1. In Mailjet, get your API key and secret key from Account settings > REST API > API Key Management and validate the sender address or domain you'll use.
  2. In Odoo, open Email Marketing > Configuration > Mailjet > Mailjet Accounts, create an account, paste the keys and press Test Connection.
  3. Fill in the Campaign Sender fields with the sender Mailjet has validated.
  4. Press Register Event Webhooks on the account so Mailjet reports sent, open, click, bounce, blocked, spam and unsub events. Mailjet has to be able to reach your Odoo from the internet for this to work.
  5. For transactional email, press Create SMTP Relay Server or Create Send API Server. Odoo's outgoing mail then goes through Mailjet.
  6. Open a mailing list and press Push to Mailjet or Pull from Mailjet, or use Import Mailjet Lists on the account to bring all your Mailjet lists in.
  7. On a mailing, choose the Mailjet account, press Mailjet Test to check it, then Send with Mailjet. Statistics are imported every three hours, or right away with Import Mailjet Stats.

Mailjet Connector: questions

Which Odoo edition do I need?

Community works. The module only depends on Odoo's Email Marketing app (mass_mailing) and doesn't need extra Python packages.

Can I send one Mailjet campaign to several Odoo lists?

No. A Mailjet campaign goes to a single Mailjet list, so the mailing must target exactly one Odoo mailing list. Odoo can still send to several lists itself if you leave the Mailjet account empty on the mailing.

What happens when someone unsubscribes or marks a mail as spam?

With the webhook registered, an unsubscribe opts the contact out of the matching Odoo list straight away. On the account you choose whether spam complaints, hard bounces and unsubscribes also add the address to Odoo's blacklist.

Is there a test mode?

Yes. Sandbox mode makes Mailjet validate Send API calls without delivering anything. For campaigns, Mailjet Test sends a test message before the real send.

Can I use it only for transactional email?

Yes. The parts are independent. You can use just the SMTP relay or Send API server, just the list sync, or all of it.

Does it work with more than one company?

Each Mailjet account record belongs to a company, so a multi-company database can hold one account per company, or a Mailjet sub-account each.
