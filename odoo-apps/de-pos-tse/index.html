Germany POS TSE

Germany KassenSichV for Odoo 19 Point of Sale: every receipt signed by a certified fiskaly cloud TSE, TSE data and QR code on the receipt, DSFinV-K export for the tax audit.

What it does

German cash registers must sign every sale with a certified technical security element (TSE) and print the TSE data on the receipt (section 146a AO, KassenSichV). This module connects Odoo POS to the fiskaly SIGN DE cloud TSE: no USB stick, the TSE is created from Odoo, each paid order is signed on the server, the receipt shows the QR code and the TSE fields, and the DSFinV-K export gives the auditor the data of every cash register closing.

DSFinV-K 2.4 export: one cash register closing per closed session, all 20 tables with the columns of the official index.xml, in one ZIP with index.xml and DTD

Features

Cloud TSE from Odoocreate, initialise and disable a fiskaly TSE per cash register; admin PIN generated and kept on the server, cash register registered as TSE client
Signature of every saletransaction start and finish with the Kassenbeleg-V1 data: amounts per VAT rate (19 %, 7 %, 7.8 %, 5.5 %, 0 %) and per payment type (cash / non cash), returns with negative amounts
ReceiptQR code (BSI TR-03153) plus transaction number, start and end, signature counter, time format, process type, TSE and cash register serial numbers and the signature
TSE failureif fiskaly or the internet is down the sale goes on, the receipt says "TSE ausgefallen" and a scheduled action signs the order again with the same TSE transaction
VAT rate check at the tilla product with a VAT rate a German TSE cannot sign is stopped before payment
TSE exportrequest the TAR export of a TSE for a period, Odoo downloads it when fiskaly has built it
Server side onlyAPI secret and admin PIN never reach the browser; the POS cannot write TSE fields
