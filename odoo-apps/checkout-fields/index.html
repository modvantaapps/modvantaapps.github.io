Checkout Custom Fields and Checkout Questions

Ask the questions your orders need, right in the checkout

View on Odoo Apps Store Ask about customisation

What it does

Add custom checkout fields - text, numbers, dates, choices, yes/no and file uploads - that are asked only when they apply, and keep every answer as data on the order.

A question can be asked only for certain products or categories, only for delivery to certain countries, only above an order amount, or only when an earlier answer was a particular value - so "How many steps to the door?" appears only after "Is there a lift?" is answered no.

Answers are stored in typed columns on the order, not as a note: you can list, filter and group them, see them on the sales order, show them to the customer in the portal and print them on the quotation. Required answers are enforced on the server, so the payment page cannot be reached without them.

Features

Each question is a recordthe wording, the type of answer, whether it is required, its limits, and when it is asked. They appear on Odoo's extra information step, between the address and the payment.
