GoBD Export

GoBD Export - GDPdU Z3 Data Carrier for Odoo 19

View on Odoo Apps Store Ask about customisation
index.xml + DTD8 CSV tablesOdoo CommunityZ2 evaluationsGerman8 + 1tables, plus attached documentsDTD

What it does

Build the data carrier for the German tax audit (Datenueberlassung, Z3) from your posted books: index.xml to the GDPdU description standard, the DTD and one CSV file per table, packed as a ZIP and checked before you hand it over.

In a German tax audit the auditor can ask for the books on a data carrier. The Bundeszentralamt fuer Steuern publishes the description standard DTD with its DSFinV-K package and says CSV files are delivered with their index.xml and that DTD. This module builds exactly that package from the posted journal entries of Odoo for the period you pick.

Each CSV file is described in index.xml: name, columns with type, length and description, separators, decimal symbol, date format, primary and foreign keys and the period. Afterwards the module reads every file back the way an import tool would and reports anything that does not match.

Nothing is transmitted to the tax authority. You download the ZIP and hand it over, and record to whom and when.
