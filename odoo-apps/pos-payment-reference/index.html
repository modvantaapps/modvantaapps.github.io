POS Payment Reference

Record the card slip, cheque or transaction number on every POS payment

View on Odoo Apps Store Ask about customisation

What it does

Each payment method can ask the cashier for a reference: optional or required, with its own name, a minimum length and a check against references already used. The reference is printed on the receipt, searchable in the backend and listed in the session report.

When a customer pays by card on a separate terminal, by cheque or by bank transfer, the till only records the amount. At the end of the day nobody can match a POS payment to the terminal slip or the cheque that was paid in.

This module adds a reference to every POS payment line. On each payment method you choose whether a reference is not used, optional or required, what it is called (for example Card slip number or Cheque number), its minimum length, and whether a reference that was already used must be refused.

On the payment screen the cashier is asked for the reference as soon as a required method is chosen, and the order cannot be validated without it. The server checks every paid order again, so a duplicate reference is refused even when the till let it through. The reference is printed on the receipt, stored on the payment, searchable in Point of Sale -> Orders -> Payments and listed in the session report.
