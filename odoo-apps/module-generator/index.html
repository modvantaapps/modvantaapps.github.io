What it does

Design a custom module in the backend, download it ready to install

Module Generator builds the skeleton of a new Odoo 19 module from a form: the manifest, your models and their fields, list, form and search views, menus and access rights.

Click Generate & Download ZIP and you get a module folder with Python models, XML views, a security file and an optional README. Install it like any other module, then keep developing it in your editor.
