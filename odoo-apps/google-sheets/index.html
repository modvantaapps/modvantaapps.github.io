Odoo Google Sheets integration

Google Sheets Connector

Keep Google Sheets filled with live Odoo data - and bring sheet rows back into Odoo

View on Odoo Apps Store Ask a question

What it does

Send any Odoo report to a Google spreadsheet on a schedule or when data changes: replace a tab, append snapshots, or update rows in place by key. Import rows that your team types into a sheet, with a check before saving and an OK or error status written next to every row.

The Google Sheets connector links Odoo to Google Sheets through the official Google Sheets API and Google Drive API. An export job takes any Odoo model, the columns you pick (plain fields or related values such as customer country), a filter and a sort, and writes them to a tab of a Google spreadsheet - one row per record or grouped totals by day, week, month, quarter or year.

An import job reads a tab, maps its columns to Odoo fields, finds linked records by name, code, e-mail, ID or external ID, and creates or updates records. Every row is checked first; the result of each row is written back into the sheet so the person who typed it sees what happened.

Who it is for

  • Managers who track numbers in a shared spreadsheet. Sales by month, open receivables or stock levels can be written to a Google Sheets tab on a schedule, so the sheet everyone already opens shows current Odoo figures without anyone copying them across.
  • Teams collecting leads or contacts in a sheet. Event staff or partners can type rows into a shared sheet. An import job maps the columns to Odoo fields, checks every row, and writes OK or ERROR with the reason back next to each row.
  • Analysts building history from daily snapshots. Append mode adds rows under the existing ones and can put the run time in the first column. That gives a history tab you can chart with ordinary sheet formulas.
  • Purchasing or pricing staff updating prices in bulk. A price list kept in a sheet can update existing products by matching on a column such as the internal reference, with empty cells left alone instead of clearing the field.

Setting it up

  1. Install the app and go to Google Sheets > Configuration > Google Connections.
  2. Create a connection and pick the sign-in: Google account (OAuth), Service account (JSON key), or Demo to try the built-in simulator with no Google account.
  3. For OAuth, paste your OAuth Client ID and OAuth Client Secret, copy the Authorized Redirect URI into your Google Cloud OAuth client, then press Connect to Google. For a service account, upload the JSON key and share each spreadsheet with the service account email.
  4. Press Test Connection, then add a spreadsheet under Google Sheets > Spreadsheets by pasting its URL, using Browse Google Drive or pressing Create in Google.
  5. Create a job from Google Sheets > New From Template, or under Exports or Imports pick the Odoo Model, Sheet Tab, columns and filter.
  6. Use Preview Rows on an export or Check Rows on an import to see the result before anything is written.
  7. Run it with Export Now or Import Now, or set the trigger to a schedule or to when data changes, and follow each run in Google Sheets > Sync Log.

Google Sheets Connector: questions

Do I need a Google Cloud project?

For real spreadsheets, yes: either your own OAuth client or a service account key. The Demo sign-in runs against a built-in simulator, so you can set up jobs and see results before creating anything at Google.

Will an export overwrite columns I added by hand?

With Update by key, rows are matched on the key column and new ones added. Columns you've added to the right of the exported ones are kept. Replace mode clears the tab and rewrites it.

Can one wrong row spoil a whole import?

Check Rows runs every row through Odoo's own rules and rolls it back, so errors show before anything is saved. Failed rows are listed on the run and can be downloaded as a CSV error report.

What happens when Google rate-limits the connector?

Requests are paced under Google's per-minute quota. Answers with status 429 or 5xx are retried with backoff, and the Sync Log records the API calls with Google's own error message.

Can users export data they aren't allowed to see?

No. Jobs read and write as their Run As user, so record rules apply. Users can only change jobs that run as themselves, and credentials are visible to administrators only.

Which Odoo edition does it need?

Community or Enterprise. It depends only on base, mail and web, and needs no Google Python library to be installed.
