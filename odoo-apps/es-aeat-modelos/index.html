What it does

Odoo Community already knows the Spanish tax boxes: the l10n_es localisation puts the AEAT tax tags on every tax. What Community does not have is the screen that adds them up and the file the AEAT asks for. This module computes the Spanish returns from your posted invoices and bills, checks them, and writes the file in the record layout published by the AEAT (diseno de registro), ready for you to upload in the AEAT e-Office.

Features

Every return in one list
Modelo 303 from your tax tags
See where each box comes from
