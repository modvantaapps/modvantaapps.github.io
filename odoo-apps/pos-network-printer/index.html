POS Network Printer

Print Point of Sale receipts and kitchen, bar and preparation tickets on ESC/POS network printers - without an IoT Box. Directly from the Odoo server, or through a small print agent when Odoo is hosted in the cloud. Cash drawer, print queue with automatic retries, printer status and test page included.

Everything a shop, cafe or restaurant needs to print from the POS.

The Odoo server sends the ESC/POS data straight to the printer on TCP port 9100. The browser never talks to the printer, so tablets, phones and laptops all print to the same network printers.

Odoo in a data centre cannot reach the printers in your shop - the print agent can. One Python file, standard library only, on any shop computer (Windows, macOS, Linux, Raspberry Pi). It polls Odoo over HTTPS with a token: no port to open in the shop firewall.

A network receipt printer per Point of Sale, and network preparation printers per product category on the standard Preparation Printers: kitchen, bar, bakery counter or any station.

Features

Check Status reads the printer statusonline, paper near end, out of paper, cover open. A printer button in the POS top bar shows green or red. The test page prints fonts, columns, logo, QR code and barcode.
