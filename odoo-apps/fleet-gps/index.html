Fleet GPS Tracking

Fleet GPS tracking and vehicle tracking inside Odoo Fleet. Connect a Traccar server, or let GPS trackers and phones send their positions straight to Odoo. See every vehicle on a live map, replay any trip, get geofence, speeding, idling and fuel drop alerts, keep the Fleet odometer up to date from the tracker and open services when maintenance is due by km.

What it does

Any company with vans, trucks, cars or field staff on the road

Everything below was used on a test database with sample data and a real local Traccar 6.16 server

Traccar REST API (email and password or API token): devices, live positions, trips, stops, events, geofences and commands. Real-time position and event forwarding into Odoo.

Phones with the free Traccar Client app and any tracker speaking the OsmAnd protocol can send positions straight to Odoo. Trips, stops and alerts are worked out in Odoo.

OpenStreetMap with Leaflet shipped in the module, no map key, or Google Maps road and satellite tiles with your own API key. Vehicles coloured by moving, idling or stopped, heading arrow, plate label, driver, speed, fuel, phone battery % and GPS accuracy.

Who it is for

  • Delivery and courier fleets. Dispatchers want to know where each van is without phoning the driver. The live map shows every vehicle with speed and status, and a Live Location Link lets a waiting customer see the van's position and an ETA without seeing its history.
  • Field service companies. Plumbers, installers and maintenance crews spend their day at customer sites. Geofences around those sites produce a visit log with arrival, departure and time spent, which helps when a customer disputes a call-out.
  • Small fleets with no hardware trackers yet. A business with a handful of cars can start with the drivers' phones. You send each driver a private link, they open it in the phone browser and press Start, and positions appear on the live map with no app to install.
  • Companies already running a Traccar server. If your trackers already report into Traccar, Odoo reads its devices, positions, trips, stops and events and can receive Traccar's real-time forwarding. Mileage then lands in the Fleet odometer log you already use.

Features

One row per vehicle and daykm, business and private km, trips, driving and idling hours, utilisation, max speed, fuel used, cost, CO2, alerts. List, pivot, graph and PDF.
Driver behaviour per monthdistance, trips, driving time, speeding, harsh driving, idling and out-of-hours use.
Proof of visit from geofence enter and exitarrival, departure and time spent.
What the customer seesthe vehicle position, distance left and ETA. The link expires on its own.
What the driver seesone big Start button, the last time the position went out, GPS accuracy, speed and battery. Without signal the points wait on the phone and go out when the connection is back. The page asks to keep the screen on while it runs.
Three fields on the serverdrop points worse than N metres, low battery level, and how often the driver page sends (10 to 600 seconds). Leave the first two at 0 and nothing changes.

Setting it up

  1. Install the module on top of the Fleet app. Two Python libraries, requests and pytz, must be available on the server.
  2. Go to Fleet > Configuration > GPS Servers and create a server. Pick Traccar server (REST API + forwarding) and enter the Traccar URL with an email and password or an API token, or pick Direct from trackers / phones if you don't run Traccar.
  3. Press Test Connection, then Read Devices. With Link devices to vehicles by plate ticked, each device whose name matches a licence plate is linked to that Fleet vehicle.
  4. On the server form, set the alert rules: default speed limit, idle alert minutes, fuel drop percentage, working hours for out-of-hours alerts and the Alert recipients.
  5. In Fleet > Configuration > Settings, under GPS Tracking, choose the Map tiles. OpenStreetMap needs no key; the Google Maps options need your own API key with the Map Tiles API enabled.
  6. Open Fleet > GPS Tracking > Live Map to see the vehicles, and add plans under Fleet > GPS Tracking > Maintenance by Distance for services due by km.

Fleet GPS Tracking: questions

Do I need a Traccar server to use this?

No. A server can be set to Direct, and then trackers speaking the OsmAnd protocol, the free Traccar Client phone app, or the driver browser page send positions straight to Odoo. Trips, stops and alerts are then worked out inside Odoo. Device commands such as engine stop are the exception: they only go through a Traccar server.

Will it work on Odoo Community?

Yes. It depends only on the Fleet and Mail apps, which are both in Community. The map uses Leaflet shipped inside the module, so there's no separate map service to sign up for unless you pick Google tiles.

How much GPS data will it store, and can I limit it?

Each server has a Keep GPS points (days) setting, 90 by default. The daily job deletes older raw points but keeps trips, stops, alerts and daily summaries. Set it to 0 to keep everything.

What happens to the Fleet odometer?

The tracker odometer, or the GPS distance if you choose that per device, is written into the standard Fleet odometer log once a day. It never writes a lower reading than the last one, and you can set a correction per device or turn the update off.

Can drivers mark trips as private?

Yes. Each trip has Mark Business and Mark Private buttons, and the daily distance report splits business and private kilometres. That's handy for mileage claims, but check the rules for your country with your accountant.

Is the driver phone link safe if it gets forwarded?

The link is private to one device and is switched on per device. A manager can press Revoke Link at any time, and New secret URL replaces it, so an old forwarded link stops working.
