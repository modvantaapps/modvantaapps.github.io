Jotform Connector | Jotform Integration for Odoo

Jotform submissions straight into Odoo leads, contacts or any model, with each submission read back from the Jotform API.

View on Odoo Apps Store Ask a question

What it does

Jotform API - Webhook with a secret address - Hourly pull - EU, HIPAA and Enterprise hosts - Any Odoo model

Paste your Jotform API key, load your forms and their questions, and choose the Odoo field each answer fills. Name fields can be split into first and last name, addresses into lines. Add the webhook from Odoo: Jotform does not sign webhooks, so each form gets its own random address and Odoo only takes the submission id from the call, then reads the submission from the Jotform API with your key. Nothing else in the posted body is used. An hourly pull catches anything that was missed.

Features

Any target modelCRM leads, contacts or your own models, with text, numbers, yes/no, dates, dropdowns, checkboxes and many2one fields.
Answer partsMap 3:first and 3:last of a full name, or the lines of an address, to separate fields.
Layout blocks skippedHeadings, buttons, page breaks and captchas are left out when the questions load.
Update or createMatch on the email (or any mapped field) to update the existing record.
Find or create the contactFor leads, the contact is found by email or created and linked.
Webhook you can trustA random secret in the address per form, a size limit, and the submission read back from the API: a forged call cannot inject data.
Hourly pullReads submissions created after the last one seen, and retries webhook calls Jotform could not be read for.
EU, HIPAA, Enterpriseapi.jotform.com, eu-api.jotform.com, hipaa-api.jotform.com or your Enterprise domain (https only).
Submission logEach submission with origin, status and error, with a Retry button.
