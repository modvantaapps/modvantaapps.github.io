Batch PDF Download

Download multiple Invoices, Sale Orders, Purchase Orders and Delivery Orders as a single ZIP file.

View on Odoo Apps Store Ask about customisation
Bulk PDF downloadDownload invoices as ZIPMass printSale ordersDelivery orders

What it does

Odoo prints several selected records into one long PDF. When your accountant, auditor or customer needs one file per document, this module adds a "Download PDFs as ZIP" action to the list views of invoices and bills, sales orders, purchase orders and transfers.

Select the records, choose the action, click Download ZIP: you get a ZIP file with one PDF per record, named after the document number (S00037.pdf, INV_2026_00012.pdf...).
