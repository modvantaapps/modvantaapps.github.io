South Africa Bankserv ACB EFT Payment File

South Africa EFT payment file: Bankserv ACB EFT file (bankserv file format, acb file) from a batch payment, for salary and creditor payments, with universal branch codes, account types, multiple action dates and contra records, non-standard account numbers, eft file for FNB online banking import.

View on Odoo Apps Store Ask about customisation

What it does

Pay South African suppliers and staff with one Bankserv ACB EFT file

South African business banking takes bulk payments as a Bankserv (ACB) EFT file: fixed 180-character records with an installation header, a user header, one record per payment, a contra record and two trailers. This module writes that file from an Odoo batch payment, in the layout FNB publishes for its Online Banking import.

Select vendor bills, pay them into a batch (the bills are reconciled at once), approve the batch and generate the file. Salary or other manual lines can be added to the same batch, each with its own action date: every action date gets its own contra record, so one file can pay on several days.

Branch codes come from the bank account or from the universal branch code of the bank, account types 0 to 6 are written as the layout requires, and account numbers longer than 11 digits go to the non-standard account field.
