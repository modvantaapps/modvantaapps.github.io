Facebook Page Feed

Your Facebook page, timeline and events on your Odoo website

View on Odoo Apps Store Ask about customisation

What it does

Set your Facebook page once in the website settings and get a ready /facebook page in the menu plus four drag-and-drop blocks - card, hero banner, feed and events, sidebar badge - all using Facebook's own Page Plugin in an iframe, with no Facebook SDK and no tracking script added to your site.

Showing your Facebook page on your website usually means pasting Facebook's SDK code into the site, which loads Facebook scripts on every page.

This module adds a Facebook Page Integration section to the website settings: your page URL, which tabs to show (timeline, events, messages or a mix), the height, small header, hidden cover and follower photos. A /facebook page with a Facebook menu entry shows the page plugin with Open in Facebook and Visit Facebook Page buttons.

Four website builder blocks reuse the same settings: a Facebook page card, a hero banner with Like and Follow buttons, a dual feed with timeline and events, and a compact sidebar badge. Every block is Facebook's Page Plugin in an iframe, so nothing depends on Facebook's SDK.
