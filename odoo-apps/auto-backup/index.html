Auto Backup

Scheduled backups of your Odoo database and filestore, made with Odoo's own dump, verified, optionally encrypted with a password, and sent to a server folder, SFTP, FTP, Amazon S3 or S3-compatible storage, Google Drive, Dropbox or OneDrive - each with its own retention. History, download, alerts and a restore guide included.

What it does

A backup you have never restored is a hope, not a backup

Everything the backup apps advertise, plus the parts that decide whether you get your data back.

The zip is exactly what the Database Manager's Backup button makes (database + filestore + manifest), so it restores with Odoo's own Restore. Or a PostgreSQL custom dump for pg_restore.

A folder on the server or a mounted NAS, SFTP, FTP / FTPS, Amazon S3 and S3-compatible storage (Wasabi, Backblaze B2, DigitalOcean Spaces, R2, MinIO), Google Drive, Dropbox and OneDrive / SharePoint. One job can send to several.

Every N hours, days, weeks or months from a start time you choose. Back Up Now queues the backup on the scheduler, so a big database never hits the browser timeout.
