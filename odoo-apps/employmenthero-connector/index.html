Employment Hero Connector

One module that brings Employment Hero employees, leave, timesheets, payslips, rosters and documents into Odoo, with webhooks and two way leave and attendance.

What it does

Built on the public Employment Hero API reference

The module uses the Employment Hero HR API with OAuth 2.0 and PKCE. Employees are created or matched by email, with manager, job title, company contact details, contractor flag and groups as tags.

Approved leave becomes approved Time Off, and timesheet entries become attendances. You can approve or decline pending requests from Odoo, and optionally send Odoo Time Off and attendances back.

Payslips, pay details, leave balances, rosters, documents and certifications are kept as read-only records. Webhooks with signature checks keep it current between scheduled syncs.

Who it is for

  • Australian and New Zealand employers on Employment Hero. If Employment Hero is your HR system and Odoo runs the rest of the business, the connector brings employees, approved leave and timesheets into the standard Odoo apps, so operations and HR stop keeping two staff lists.
  • Managers who approve leave in Odoo. Pending leave requests and timesheets can be approved or declined from Odoo. The decision is sent to Employment Hero, and approved leave turns into validated Time Off.
  • Businesses that roster shift workers. Rostered shifts come across into a list and a calendar, and timesheet entries with a start and end time become Odoo attendances, which is handy where Odoo already plans the work.
  • Companies that track staff certifications. Certifications with completion and expiry dates and employee documents are pulled in as read-only records, so supervisors can check them next to the employee without logging into another system.

Setting it up

  1. In the Employment Hero Developer Portal create an OAuth application with the scopes you need.
  2. In Odoo open Employment Hero > Connections and create a connection. Copy the Redirect URI shown on the form into your OAuth application, then enter the Client ID and client secret.
  3. Click Authorise, sign in with an Employment Hero admin or owner account and pick the Organisation this connection should read.
  4. Under What to Sync, switch each area on or off. Private Details, Send Odoo Time Off and Send Attendances are off until you turn them on, and Look-back Days and Look-ahead Days set the date window.
  5. Map each entry under Employment Hero > Configuration > Leave Categories to an Odoo Time Off type, or leave it empty to use or create a type with the same name.
  6. Copy the Webhook URL into the webhook page of the Developer Portal and paste the portal's secret into the connection.
  7. Click Test Connection, then Sync Everything. A scheduled job repeats the full sync every six hours and processes waiting webhook events every five minutes.

Employment Hero Connector: questions

Which Employment Hero plan is needed?

You need a plan that gives you API and webhook access. Employment Hero says that's Platinum and above, so check your subscription with them before buying.

Does it run payroll?

No. Payslips, pay details and leave balances are read from Employment Hero and kept in Odoo as read-only records. The connector uses the HR API, not the separate Employment Hero Payroll API that used to be called KeyPay.

Can I try it without an Employment Hero account?

Yes. Tick Demo Mode on the connection and it uses a built-in simulator of the documented API, with no network calls. The module was built from the public API reference, so test it on a copy of your database before switching it on for real staff.

What happens when a leave request clashes with existing Time Off?

Odoo won't book overlapping Time Off, so the request is kept and the reason is shown on it. If a request is later declined or deleted in Employment Hero, the Time Off it created is cancelled.

Does it create new employees in Employment Hero?

No. Employees flow from Employment Hero to Odoo, matched by email or created when missing. The only thing written back on the employee is the company email, mobile and landline, using Send Contact Details.

Do I need Odoo Enterprise?

No. It needs Employees, Time Off and Attendances, all part of Community. Enterprise apps like Planning, Work Entries and Documents aren't used.
