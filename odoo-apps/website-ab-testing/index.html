Storefront A/B Testing

A/B test your Odoo shop and read the results in Odoo

View on Odoo Apps Store Ask about customisation

What it does

Split your eCommerce visitors between variants of the Add to Cart button - different wording, different styling - and measure page views, add to cart, checkout or completed orders, with conversion rate, revenue and revenue per visitor for each variant.

Changing a button label or style on a hunch tells you nothing. A split test shows half of the visitors one version and half the other, and counts which one sells more.

This module adds A/B testing experiments to the Website app. An experiment runs on a page or a group of pages, splits visitors between its variants by weight, and keeps each visitor on the same variant while they browse. A variant can change the Add to Cart label and add CSS classes to it.

Each experiment has a goal - page view, add to cart, begin checkout, CTA click or order completed. Conversions are counted once per visitor; for completed orders the order amount is added to the variant's revenue. Administrators and website editors are never counted.
