Nepal Payment Gateway

Take eSewa and Khalti payments in Odoo 19, verified with each wallet before an order is confirmed

View on Odoo Apps Store Ask about customisation
eSewaKhaltiePay v2KPG-2NepalNPR

What it does

Adds eSewa and Khalti as two payment providers in Odoo, in one module. The customer pays in the wallet and comes back; Odoo checks the result with the wallet server before it confirms the order. Khalti refunds are made from Odoo.

Features

eSewa ePay v2signed form with HMAC-SHA256, signature check on the answer, then the status check API decides
Khalti web checkout (KPG-2)initiate and lookup APIs with amounts in paisa; the lookup API decides, not the callback
Khalti refundsfull or partial from Odoo, including the mobile number that bank payments require
Pending payments re-checkedneither wallet publishes a webhook, so a scheduled action checks open payments every 15 minutes
Amount checka wrong amount puts the payment in error
Point of Salewith Odoo online payment; neither wallet requires customer details, so an order with no customer can pay and nothing is invented
Test and productioneach provider has its own keys and uses the wallet test servers in Test mode
API logeach call and return, with signatures and customer details masked
Nepalitranslation included; Odoo 19 ships no Nepali language, so the module adds one that you switch on in Settings > Languages
