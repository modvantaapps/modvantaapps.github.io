Contact Number / Customer ID Generator

Auto-generate a unique, sequential customer/vendor reference number with a configurable prefix and suffix on every new contact. Auto number, sequence generator, customer ID, unique reference.

View on Odoo Apps Store Ask about customisation

What it does

Many businesses quote a customer number on the phone, on documents and in other systems. Odoo has a free-text Reference field, so numbers are typed by hand, skipped or duplicated.

This module gives each new contact an automatic reference such as CUST-000034, built from a prefix, a sequential number with fixed padding, and an optional suffix. The reference is shown under the contact name, in a Ref column in the contact list, and can be searched. Existing contacts can be numbered in bulk from the list with the Generate Contact Reference action.
