Elasticsearch Backend Search

Typo tolerant full text search in the Odoo backend: index the models and fields you choose in Elasticsearch and search them from the normal search bar or one global search.

View on Odoo Apps Store Ask about customisation
Elasticsearch Backend Search for Odoo 19

What it does

Elasticsearch and OpenSearchFuzzy searchGlobal searchReal-time syncFallback searchOdoo 19

You pick a model, for example Contacts or Products, and the fields to index.

A Full-text Search entry appears in the search bar of that model. Typos still find the record.

Changes are sent to Elasticsearch right after they are saved, and the whole index is rebuilt every night.

Features

Connection to your Elasticsearch server
Index mapping
Full-text Search in the search bar
Typo tolerant results
Any model, for example products
Global search
Group based search rules
Index status and sync queue
