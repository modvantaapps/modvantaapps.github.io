Exit Intent Discount Popup

Show a discount popup right when a visitor is about to leave your store

View on Odoo Apps Store Ask about customisation
Exit intent popupDiscount popupCoupon popupReduce bounce

What it does

When a desktop visitor moves the mouse towards the top of the browser to close the tab or leave, this module shows a popup with your title, your message and, if you want, a coupon code.

The popup appears once per browser session, so it never nags. Title, message and coupon are set in Website Settings.
