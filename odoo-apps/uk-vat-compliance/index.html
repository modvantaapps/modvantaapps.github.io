What it does

Compute the nine-box UK VAT return from your own posted entries in Odoo Community, drill into every box, and run eight audit checks that catch the VAT a finished return cannot show you - before you file.

Odoo Community already loads the UK VAT100 definition with the UK chart of accounts, and every posted journal item already carries its tax tags. What is missing in Community is the engine that adds them up. This module is that engine: it reads the same VAT100 definition and totals your posted journal items for the period.

Each box that reads tax tags has a Journal Items button that opens exactly the entries behind the figure. Before you mark a return reviewed, eight checks look for the problems that never show on the return itself: draft invoices in the period, tax lines with no tag, entries added to a filed period, bills keyed twice, EU movements with no VAT number, lines with no tax, gaps since the last return and an unusual VAT share of sales.

Submitting a return moves Odoo's own tax lock date to the end of the period, so nothing more can be posted into a quarter you have filed. The module does not send anything to HMRC.
