Gantt View

A real Gantt chart and project scheduler for Odoo Community - critical path, baselines, MS Project XML

View on Odoo Apps Store Ask about customisation

What it does

Adds a gantt view type to Odoo 19 Community with ready-made charts on tasks, manufacturing orders, work orders and time off, and turns the task gantt into a scheduler: four dependency types with lag, the critical path, task constraints, auto-scheduling in working time, saved baselines, resource load per person, and Microsoft Project XML import and export.

The module adds a new gantt view type that any window action can use. It is installed on All Tasks, My Tasks and a project's tasks (grouped by assignee), on Manufacturing Orders (grouped by product), on Work Orders (grouped by work center) and on All Time Off (grouped by employee), next to the list, kanban and other views.

On tasks it is also a project scheduler. Each dependency has a type - Finish to Start, Start to Start, Finish to Finish or Start to Finish - and a lag or a lead in days. The critical path is computed on the server and drawn in red, bars and arrows, with the total slack of every task. Tasks can carry a constraint (Start No Earlier Than, Finish No Later Than, Must Start On) or be pinned as manual.

Switch on auto-scheduling on a project and the successors move when a task's dates or links change, or run the scheduler on the whole project and check the preview before anything is saved. With Respect Working Time the plan skips weekends, company closing days and the assignee's time off.

Save a baseline of the plan and the gantt draws it as a grey bar under every task, with the variance in days. The resource load shows the planned hours of each person per day, week or month against their working hours. Plans come in and go out as Microsoft Project XML, and the gantt prints as a PDF, downloads as a PNG image and exports to Excel and iCal.
