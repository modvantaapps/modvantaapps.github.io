Dot Matrix Printing

Print invoices, orders and delivery slips on dot matrix printers at full speed - as text, not as slow PDF pictures

View on Odoo Apps Store Ask about customisation

What it does

Odoo prints every document as a PDF. A dot matrix printer prints a PDF as a picture: slowly, grey, and often unreadable on carbon copies. This module sends plain text with Epson ESC/P codes instead, laid out in fixed columns for your continuous, pre-printed and multi-part forms.

The module turns the template into printer bytes: initialize, pitch (10, 12, 15 cpi or condensed), draft or NLQ, line spacing, page length, perforation skip, left margin and character table, all from the Epson ESC/P reference. Long documents run over several pages with the header repeated, a "continued" line, and the totals at the bottom of the last form.

Who it is for

  • Distributors printing on carbon multi-part forms. A dot matrix printer prints Odoo's PDFs as pictures, which is slow and often too faint for the second and third copy. This sends plain text with Epson ESC/P codes, so a 3-part invoice prints at the printer's normal text speed.
  • Businesses with pre-printed stationery. When the logo and boxes are already on the paper, every value has to land in a fixed column. Text templates with placeholders like ljust and rjust place each field exactly, and the footer can be pushed to the bottom of the form so totals sit in the total box.
  • Warehouses printing delivery slips on the dock. A network dot matrix printer on port 9100 can receive delivery slips sent straight from the Odoo server, with no PC at the printer.
  • Counters that keep a dot matrix receipt printer. A Dot Matrix Receipt button can be added to the POS receipt screen to print the ticket on continuous roll paper.

Features

You write a text template for each documenta header, a line section that repeats for every invoice or order line, and a footer. Placeholders such as {{ object.partner_id.name | ljust:40 }} or {{ line.price_subtotal | money | rjust:12 }} put each value in its exact column. Six templates come ready: invoice, sales order, purchase order, delivery slip, POS receipt and payment receipt.

Setting it up

  1. Install the module. It brings ready templates for invoices, sales orders, purchase orders, delivery slips, POS receipts and payment receipts.
  2. Go to Dot Matrix > Configuration > Printers and add a printer: local print agent, network printer on raw TCP port 9100, .prn download, or browser print. Press Test Connection.
  3. For a USB or parallel printer, open Dot Matrix > Configuration > My Print Agent, press Generate Key and Files, and run the agent with the shown command on the computer the printer is attached to.
  4. Open Dot Matrix > Configuration > Templates and adjust columns, Page Length (lines), margins and the ESC/P codes to match your paper. Check the Live Preview with a sample record.
  5. To print from another Odoo model, set the Document Model on a template and press Add to Print Menu.
  6. Open an invoice, order or transfer and press Dot Matrix, or select several records in a list to print them in one job.
  7. Check past prints in Dot Matrix > Print Jobs, where you can use Print Again or download the .prn and .txt files.

Dot Matrix Printing: questions

Can the templates run code?

No. Placeholders are limited to field values and a fixed set of filters such as money, words, date and upper. They don't execute Python, so a template edit can't run arbitrary code.

How do long invoices spread over several forms?

Set the page length in lines (66 for 11 inch, 33 for 5.5 inch). The module breaks pages, can repeat the header, prints a continued line, and puts the footer on the last page.

My printer has no carbon paper. Can it print copies?

Yes. Set Copies on the template and add copy labels such as ORIGINAL, DUPLICATE, TRIPLICATE, which you print with a placeholder in the header.

What about accented letters?

Choose the Character Table your printer uses, such as PC437, PC850 or ISO 8859-1. With Replace Unprintable Accents ticked, characters missing from that table print without the accent instead of as garbage.

Is the print agent safe to run?

It listens only on the local computer, accepts requests from the Odoo address you set, and prints only to the printer queues you allow. Each user gets a personal key.

Which Odoo apps does it need?

It depends on Invoicing, Sales, Purchase, Inventory and Point of Sale, and runs on Community or Enterprise.
