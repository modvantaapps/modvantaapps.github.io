Kopo Kopo M-PESA Payment Kenya

Kopo Kopo for Odoo 19: M-PESA STK Push on your website and invoices, signed results, reversals and till payments

View on Odoo Apps Store Ask a question

What it does

Kopo Kopo K2 Connect - M-PESA STK Push - KES - Reversal refunds - Till payments log

Kopo Kopo lets Kenyan businesses take M-PESA payments on a till. This module adds it to Odoo as a payment provider. The customer types an M-PESA number at checkout, Odoo sends the STK Push and the phone asks for the PIN. Kopo Kopo posts the result back to Odoo, signed with your API key; Odoo checks that signature, the amount, the currency and the till before the order is marked paid.

Features

STK Push from Odooincoming payment request to your till with the order reference in the metadata
Signed resultsX-KopoKopo-Signature (HMAC-SHA256 with your API key) checked before anything is read
Checks before confirmingamount, KES currency and till number must match
Waiting paymentsqueried every 5 minutes and from a Check Status button if the webhook is late
Reversal refundsa Reverse on Kopo Kopo button on the paid payment returns the whole M-PESA amount (last 30 days)
Till payments logevery M-PESA payment to the till, also those made outside Odoo, from the till webhooks
Customer matchingtill payments linked to the customer with the same phone, in the same company only
Webhook subscriptionone button subscribes your Odoo URL to the till events
Sandbox and productiontest mode uses sandbox.kopokopo.com
API logcalls and webhooks logged with client ID, secret, token and phone numbers masked
