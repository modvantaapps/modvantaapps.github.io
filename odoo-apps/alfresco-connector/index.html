Alfresco Connector

The files of your Odoo records, kept in Alfresco folders with their version history

View on Odoo Apps Store Ask a question

What it does

Alfresco REST API v1 - Folder per record - Attachments to Alfresco - New versions - Browse, link, download

When Alfresco is your company repository, files attached in Odoo end up in two places or, worse, only in Odoo. This connector gives every Odoo record its own Alfresco folder, built from a pattern you choose, for example Invoices/2026/INV-2026-00010 or Customers/Maple Street Bakery. Attachments go there by button, from the Action menu or on a schedule. When an attachment changes in Odoo, Alfresco gets a new version of the same file instead of a copy. From the record you can open its folder, look at the version history, download an older version, or link a file that already lives elsewhere in Alfresco.

Features

Sign-inAlfresco ticket (one sign-in, then the ticket) or HTTP Basic, with one service user you create in Alfresco
Start folderCompany Home (-root-), Shared, the user home or any node id, with an Odoo folder under it
Folder rulesper Odoo model, with a domain and a path pattern using {model}, {name}, {id} and {year}
Folders made for youmissing folders are created one level at a time; names are cleaned of characters Alfresco refuses
Upload attachmentsby button, Action menu entry or every 15 minutes; filter by file type
Versionsa changed attachment becomes a new minor or major Alfresco version with a comment; unchanged files are skipped
Browse from the recordits folder with name, version, type, size and date; move up and into folders
Version historylist the versions of a file and download any of them as an attachment
Linkattach a reference to an Alfresco file without copying it into Odoo
Kept inside the start folderOdoo users can browse, link and download only below the start folder of the connection
Logevery upload, new version, link and download with who did it
