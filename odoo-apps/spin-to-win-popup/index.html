Spin to Win Popup

Turn visitors into subscribers with a spin-the-wheel coupon popup

View on Odoo Apps Store Ask about customisation

What it does

Visitors enter their email, spin the wheel and win a unique coupon code generated in an Odoo coupon program. The code works in the cart straight away, and every email is saved as a lead.

The popup shows a colourful wheel with your segments - for example 10% OFF, 5% OFF, 15% OFF and 'No luck'. The visitor types an email and spins. The winning segment is drawn on the server with the weights you set, so nobody can change the result in the browser.

A winning segment creates a real coupon (loyalty card) in the Odoo coupon program you linked to it, with its own unique code and an expiry date. The winner can copy the code or press 'Apply to my cart', which adds the discount to their cart with Odoo's own coupon engine.

Every email is stored with the result and the coupon code, and a contact is created so you can use it in your marketing. One email can play once per campaign, and a daily limit per connection stops people collecting codes with made-up addresses.
