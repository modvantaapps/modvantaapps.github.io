Odoo REST API

REST API for Odoo with an OAuth2 API server: clean JSON endpoints with resource aliases, per model and per field permissions, read only by default, OpenAPI schema and Swagger UI generated from your own configuration, REST API OAuth2 with client credentials, authorization code and PKCE, scoped API keys, report API for PDF reports, attachment upload and download, no-code custom endpoint builder, Postman collection export, model explorer, ETag concurrency control, idempotent writes, rate limits, a kill switch and a full audit log of every call.

What it does

A REST API and OAuth2 server for Odoo, documented from your own permissions

Connecting a webshop, a mobile app or a data tool to Odoo usually means XML-RPC and a full user login. This module adds a plain JSON REST API under /api/v1 with standard verbs and status codes, API keys that only work for this API, and an OAuth2 server for applications that act for a person.

Features

You decide what each integration may touchresources per model, readable and writable fields, which reports it may print, whether it may read or upload attachments, and no-code custom endpoints for one job. Scopes narrow each key and each OAuth2 client further. Every call runs as an Odoo user, so record rules and multi-company rules always apply, and every call is logged.
