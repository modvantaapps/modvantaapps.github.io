Accounting Sync Base

Accounting Sync Base is the shared foundation the accounting connectors run on: a dashboard, a job queue that retries, a mapping between Odoo and remote records, a dry run, a sync log of every exchange and encrypted credential storage. It is installed automatically with a connector.

View on Odoo Apps Store Ask about customisation

What it does

Every accounting connector needs the same machinery besides the provider's API: remember which Odoo record is which remote record, queue changes and retry when the other side is down, stop and explain what cannot be sent, and log exactly what was exchanged. This module provides that once, for all connectors.

Credentials for connectors that need them are encrypted with a key kept in odoo.conf, outside the database, so a database dump on its own contains nothing usable.

Features

Sync dashboard
A queue that retries
Per-entity settings
Mapping between Odoo and remote records
Sync results over time
What was sent and what came back
Dry run before sending
