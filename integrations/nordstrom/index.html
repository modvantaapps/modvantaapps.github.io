How Odoo connects to Nordstrom

Nordstrom's marketplace runs on Mirakl. Once Nordstrom approves you as a seller, it gives you a Mirakl API key, and our Mirakl Connector links that seller account to Odoo.

Nordstrom, Decathlon, Carrefour, Leroy Merlin, Worten, Fnac Darty, Best Buy Canada, Maisons du Monde, Castorama, Conforama, MediaMarkt, The Bay: each one is a Mirakl instance URL and a shop API key. One module connects them all on the Mirakl seller API - orders with acceptance, offers, stock, prices, tracking, cancellations, refunds, invoices and customer messages.

Frequently asked questions

Is there an Odoo Nordstrom connector?

Nordstrom's marketplace runs on Mirakl. Once Nordstrom approves you as a seller, it gives you a Mirakl API key, and our Mirakl Connector links that seller account to Odoo.

What does the Odoo Nordstrom integration sync?

Products, prices and stock go from Odoo to the marketplace; orders come back into Odoo as sales orders, with shipping and tracking sent back. The connector page lists every feature.

Can you set it up for us?

Yes. We install the connector, connect your seller account, map your products and test the first orders with you, at a fixed price.
