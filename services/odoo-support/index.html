What we do

We fix bugs in custom and third-party Odoo modules, review code for security problems such as unsafe routes, injection and leaked tokens, and keep integrations running when the other side changes its API. We reproduce every problem on a clean database first, so the fix addresses the cause and not the symptom.

Frequently asked questions

Do you support modules you did not write?

Yes. Send us the module and a description of the problem; we review it before quoting.

How do we report a problem?

Email us the module, your Odoo version, the steps to reproduce and any error message or screenshot.

Do you check security?

Yes. We review routes, access rules, uploads, SQL and secret handling in the code we work on.

Can you work on our server?

We prefer to reproduce on a copy first, then deploy the fix with you.

Have a project in mind?

Tell us what you need. We reply with a clear scope and a fixed quote before any work starts.
