Odoo Upgrade & Migration

Move to a newer Odoo version without losing the custom features your team relies on.

What we do

Each Odoo version changes fields, views and frontend code, so custom modules have to be ported. We port modules between Odoo 17, 18 and 19, rewrite what the new framework no longer accepts, and test the result on a copy of your database before the switch.

Frequently asked questions

Which versions can you upgrade between?

We port modules between Odoo 17, 18 and 19.

Will our data be upgraded too?

The database upgrade itself depends on your edition: Enterprise uses Odoo's upgrade service, Community uses the community migration scripts. We port your custom modules and test the upgraded database.

How long does an upgrade take?

It depends on how many custom modules you have. We give you an estimate after the module audit.

Can we stay on our version and only fix problems?

Yes. We also maintain modules on the version you run today.
