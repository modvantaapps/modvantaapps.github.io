Support

For questions about installing, configuring or using a Modvanta extension, email modvantaapps@gmail.com.

What to include

  • The extension name and version
  • Your Magento and PHP versions
  • What you did, what you expected, and what happened, with any error message
  • Screenshots if they help

Response time

We aim to reply within two working days.

Before you write

Every extension includes a PDF user guide with installation steps, every setting, and known limitations. Many answers are there.

Please never send passwords, API keys or customer data by email. If we need access to investigate, we will ask for it in a safe way.
