What it does

Edit many products at once in a spreadsheet-style grid in the admin. Changes are collected into a change set you can preview before applying and undo afterwards.

This extension lets you edit many products at once in a spreadsheet-style grid under Catalog > Bulk Product Editor. You select products by category, attribute set, SKU, name or status, choose the columns, pick the default scope or a store view, and edit cells inline. Bulk formulas change a whole column at once: set a value, add or subtract an amount or percentage, round to .99, find and replace text or copy from another attribute. Edits are validated, and Preview Changes shows old and new values before anything is saved. Large change sets are applied in the background, and Change Sets & Undo lets you reverse a change set later, unless affected values changed since. CSV export and import are included. In the configuration you set rows per page, limits and redirects for changed URL keys. A typical use is a 10 percent price rise on one category.

Features

  • Filter products by category, attribute set, type, status and stock
  • Edit price, special price, quantity, stock status, status and other attributes in the grid
  • Per store view
  • Formulas for a whole column, such as raise prices by a percentage
  • Validation before anything is saved
  • Preview that lists every old and new value
  • Changes are applied in batches
  • Change set history with undo
  • CSV export and import
  • Separate permissions for viewing, editing and applying

Where you find it in the admin

  • Catalog > Bulk Product Editor > Bulk Product Editor
  • Catalog > Bulk Product Editor > Change Sets & Undo

Bulk Product Editor Spreadsheet: questions

Which Magento versions does Bulk Product Editor Spreadsheet support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Bulk Product Editor Spreadsheet cost?

$39 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Bulk Product Editor Spreadsheet?

With Composer: composer require modvanta/module-bulk-product-editor, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
