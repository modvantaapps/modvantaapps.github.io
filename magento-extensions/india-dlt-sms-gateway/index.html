What it does

A TRAI DLT-compliant SMS gateway stores in India. It provides

This tool sends order SMS to customers in India in line with TRAI's DLT rules. Under Marketing > DLT SMS > Templates the merchant registers each approved template with its header, PE ID, category and {#var#} placeholders. Messages can go out when an order is placed, for COD confirmation, when a shipment or tracking number is added, and when an order is cancelled. Each message is checked against the URL whitelist, the promotional time window, recorded consent and the segment limit. Messages are queued and sent through MSG91, Kaleyra or Gupshup in a chosen failover order, with retries and delivery reports, or a mock for testing. The admin has a message log with masked numbers, a test send page and statistics. Merchants set provider keys, the window, COD methods and tracking URL pattern. COD order confirmation is a typical use.

Features

  • Template registry with header binding
  • {#var#} rendering
  • URL whitelist
  • Promotional time window and consent checks
  • Provider failover (mock, MSG91, Kaleyra, Gupshup)
  • Queue-based delivery with retries and delivery reports

Where you find it in the admin

  • Marketing > DLT SMS > Templates
  • Marketing > DLT SMS > Message Log
  • Marketing > DLT SMS > Test Send
  • Marketing > DLT SMS > Statistics
  • Marketing > DLT SMS > Configuration

Good to know

This module helps you comply with TRAI's TCCCPR 2018 (as amended) and the DLT directions. It does not certify compliance. Your registrations on the operators' DLT portals and the operators' own scrubbing always take priority.

India DLT SMS Gateway: questions

Which Magento versions does India DLT SMS Gateway support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does India DLT SMS Gateway cost?

$50 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install India DLT SMS Gateway?

With Composer: composer require modvanta/module-dlt-sms, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
