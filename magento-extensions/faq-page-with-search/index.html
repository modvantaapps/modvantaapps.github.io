What it does

Add a Frequently Asked Questions page to your store at /faq. Questions are grouped under your own categories, open and close as an accordion, and can be searched while the visitor types. Questions can also be shown on product pages in their own tab, assigned by SKU or by catalog category. The FAQ page carries FAQPage structured data for search engines and stays compatible with full page cache.

Add a Frequently Asked Questions page at /faq that answers common questions. Under Content > FAQ you create categories and questions with sort order, an Active switch and store views; answers can be plain text or simple HTML. On the storefront, questions sit under category headings and open as an accordion that works with the keyboard and without JavaScript, and a search box filters the list as the visitor types. Questions assigned to SKUs or catalog category IDs also appear on those product pages in a Questions about this product tab. A footer link and FAQPage structured data are added, In its section under Stores > Configuration you set the page title, meta description and link text, and switch the search box, tab and structured data on or off. For example, a shoe shop can answer sizing questions on every product in one category.

Features

  • FAQ page at /faq with questions grouped by category and sorted in your order
  • Accordion built on standard browser elements: works with the keyboard and without JavaScript
  • Search box that filters while typing, with a server-side search fallback
  • Questions about this product tab on product pages, by SKU or catalog category ID; shown only where questions exist
  • FAQPage structured data (JSON-LD) on the FAQ page
  • Footer link with your own text; can be switched off
  • Active switch, sort order and store views per category and per question
  • Answers in plain text or simple HTML such as bold, italics, lists and links; unsafe markup is shown as text
  • Admin grids with filters and bulk delete
  • Cached pages refresh automatically when a question or category is saved

Good to know

No WYSIWYG editor, images or customer-submitted questions. Whether a search engine shows rich results is decided by the search engine.

FAQ Page With Search: questions

Which Magento versions does FAQ Page With Search support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does FAQ Page With Search cost?

$25 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install FAQ Page With Search?

With Composer: composer require modvanta/module-faq, then bin/magento setup:upgrade. We can also install and configure it on your store.
