What it does

Faster filtering for Luma category and search pages. Shoppers can select several values per filter, the product list updates without a page reload, and filtered pages get readable URLs.

This extension makes filtering on Luma category and search pages faster and more flexible. Shoppers can select several values per filter, for example red and blue, and the product list, counts, sorting and paging update without a page reload, while the browser back button keeps working. It adds a keyboard-operable price slider, a 4 stars and up rating filter, an In stock only filter, Show more for long lists, an option search box and a summary of selected filters with Clear All. Filtered pages get readable URLs such as /tops/color-blue-red, with canonical and noindex rules to avoid duplicate content. Per attribute, under Stores > Attributes > Layered Navigation, you choose multi-select, display as checkboxes, links, dropdown or swatches, option sorting and URL key. In Stores > Configuration you set the URL format, counts, filters and SEO thresholds. A fashion store with many colours and sizes is a typical case.

Features

  • Multi-select filters: several values within one attribute, combined across attributes
  • Option counts that stay correct while filters are selected
  • Product list, filters and URL update by AJAX, with the browser Back button working
  • Readable filter URLs as path segments or query parameters
  • Canonical and robots rules for filtered pages
  • Price slider usable with the keyboard
  • Rating and stock filters
  • Show more and search inside long option lists
  • Settings per attribute in the admin
  • Falls back to normal page loads when JavaScript is unavailable

Where you find it in the admin

  • Stores > Attributes > Layered Navigation

Ajax Layered Navigation: questions

Which Magento versions does Ajax Layered Navigation support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Ajax Layered Navigation cost?

$45 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Ajax Layered Navigation?

With Composer: composer require modvanta/module-ajax-layered-navigation, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
