What it does

Connect your store to no-code automation tools. The store sends signed webhooks when orders, shipments, customers, products, stock, reviews and carts change, and the tool can call back to comment on orders, create shipments with tracking, update prices and stock, create coupon codes and more. It uses its own API keys with per-key permissions and request limits, a retrying delivery queue and a full delivery log.

This extension lets your automation tool react to what happens in the store and make changes in it, without custom code. Fifteen triggers, including order placed, shipment created with tracking, low stock, new review and abandoned cart, are queued and sent by cron as signed webhooks and retried if delivery fails. In the other direction, your workflows can add order comments, hold, release or cancel orders, create shipments with tracking, update price and stock by SKU, create coupon codes and look up orders, customers or products. In the admin, screens under System > Automation Connector manage API keys with permissions and request limits per key, subscriptions with a Send Test button, and a delivery log with Resend. Under Stores > Configuration you set the low-stock threshold, the abandoned cart delay and the number of retries. The storefront does not change, and the full source code is included if you need extra triggers or actions. For example, a shop can post new orders to a team chat, add customers to a mailing list or push tracking numbers from a warehouse system.

Features

  • 15 triggers: order placed and status changed, invoice paid, shipment created, tracking added, credit memo, customer registered and updated, newsletter subscribed and unsubscribed, product created and updated, low stock, new review, abandoned cart
  • 9 actions: customer create or update, order comment, hold, unhold, cancel, shipment with tracking, product price and stock by SKU, coupon code from a cart rule, newsletter subscribe
  • Order, customer and product searches
  • API keys shown once and stored as a hash, with per-key permissions and a rate limit
  • Subscribe and unsubscribe API plus sample records for field mapping
  • HMAC-SHA256 signed deliveries, retried with growing pauses; failing targets are switched off automatically
  • Delivery log with the payload sent, the answer received and Resend
  • Idempotency key support, so a retried action is not executed twice
  • Private and loopback target addresses refused by default
  • Mock mode to try everything without an automation account

Good to know

This is not a listed app in the Zapier, Make or n8n directories: it works through their generic Webhook and HTTP modules, and Zapier webhooks need a paid Zapier plan. Requires the store cron and an HTTPS store. All triggers and actions were verified against a local receiver; it has not been run with a live Zapier, Make or n8n account.

Zapier Make & N8n Connector: questions

Which Magento versions does Zapier Make & N8n Connector support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Zapier Make & N8n Connector cost?

$50 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Zapier Make & N8n Connector?

With Composer: composer require modvanta/module-automation-connector, then bin/magento setup:upgrade. We can also install and configure it on your store.
