What it does

Send orders, order items, customers, products, stock, invoices, credit memos and newsletter subscribers to Google Sheets tabs with the columns you choose, by hand, on a schedule, or as new records arrive. Edit prices, quantities, names and statuses in a sheet, preview exactly what would change, then apply the changes by SKU. It uses a Google service account; no extra PHP library is needed.

This extension keeps store data up to date in Google Sheets and can bring product changes made in a sheet back into the store. Export profiles under System > Google Sheets Sync > Profiles send orders, order items, customers, products, stock, invoices, credit memos or newsletter subscribers to a sheet tab, with the columns you pick and filters by status, date and store view. Each profile can run by hand, as a scheduled full refresh from every 15 minutes to once a week, or by adding new records as they are created. Import profiles read name, price, special price, quantity and status by SKU; Preview Import lists every change and error before Apply Import updates the products, and the result of each row can be written back to the sheet. A run log shows progress and messages. All screens are in the admin and the storefront does not change. Columns, filters and schedules are set per profile, and the full source code is included. For example, a team can share a live orders sheet with the warehouse, or a buyer can reprice a range in a sheet and check every change before it goes live.

Features

  • Export profiles for 8 kinds of data with a selectable, ordered column list
  • Filters by status, creation date and store view
  • Three modes: manual, full refresh on a schedule, or append new rows as they happen
  • Import preview lists every row that would change and every row with an error, and changes nothing
  • Apply Import updates name, price, special price, quantity and status by SKU
  • Test Connection button and plain messages for no access and not found
  • Run log with progress, counters and messages; quota and server errors are retried automatically
  • Service-account key stored encrypted and shown only as asterisks
  • Separate permissions for viewing, saving, running, applying imports and the run log
  • Mock mode to try every screen without a Google account

Good to know

Requires a free Google Cloud service account with the Sheets API enabled, each spreadsheet shared with it, and the store cron. Verified end to end in Mock mode; the real Google sign-in was checked only as far as Google's refusal of a test key, so run Test Connection and one export against your own spreadsheet first.

Google Sheets Sync: questions

Which Magento versions does Google Sheets Sync support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Google Sheets Sync cost?

$30 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Google Sheets Sync?

With Composer: composer require modvanta/module-google-sheets-sync, then bin/magento setup:upgrade. We can also install and configure it on your store.
