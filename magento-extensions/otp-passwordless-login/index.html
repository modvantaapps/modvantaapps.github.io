What it does

Let customers sign in with a six-digit one-time code sent by email or SMS instead of a password. Optionally collect a mobile number at registration and in the account, and confirm it by SMS before it is saved. Codes expire, work once, and are rate limited.

Let customers sign in without a password: they enter their email address or mobile number on the login page, receive a six-digit code by email or SMS, and type it in. A Log In With a Code form appears next to the normal login, and you can add a mobile number field to registration and My Account > Account Information, with optional SMS confirmation before a number is saved. In its section under Stores > Configuration you choose the channels, code lifetime, wrong entries allowed and limits per address, number and IP. SMS goes through Twilio, a generic HTTP gateway or a test mode that logs codes. The email template, sender and SMS text can change per store view, other settings per website. For example, a store whose customers often forget passwords can reduce abandoned logins, and a courier-delivery shop can confirm every mobile number.

Features

  • Log In With a Code form on the customer login page, next to the password login
  • Codes by email, with an editable email template, or by SMS to the saved mobile number
  • Mobile number field on registration, account edit and the admin customer page, stored in international format
  • Optional SMS confirmation of a new or changed number; one number per account
  • SMS through Twilio or any SMS gateway with an HTTP API: configurable URL, method, body, headers and secret
  • Test mode that writes messages to a log file, with an admin warning while it is on
  • Limits for code lifetime, wrong entries per code, resend wait, and codes per address, number and IP address
  • The same answer for known and unknown addresses, so accounts cannot be probed
  • Locked accounts cannot sign in with a code

Good to know

SMS delivery needs a Twilio account or an SMS gateway with an HTTP API. Email codes need no external service.

OTP Passwordless Login: questions

Which Magento versions does OTP Passwordless Login support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does OTP Passwordless Login cost?

$30 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install OTP Passwordless Login?

With Composer: composer require modvanta/module-otp-login, then bin/magento setup:upgrade. We can also install and configure it on your store.
