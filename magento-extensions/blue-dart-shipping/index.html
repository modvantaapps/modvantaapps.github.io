What it does

Offer Blue Dart at checkout for Indian pincodes with prices from your own table, hide it for pincodes that are not serviceable, and generate prepaid or cash on delivery waybills with the Blue Dart label from the shipment page. The waybill number is saved as the tracking number and customers see the scan history in the tracking window. A built-in Mock mode lets you try the whole flow without Blue Dart credentials.

Shoppers with an Indian pincode see your Blue Dart products as delivery methods with your own titles, and the Location Finder can hide them where Blue Dart does not deliver. In Stores > Configuration > Sales > Delivery Methods you enter your API credentials, customer code and origin area, list your contract's product and sub product codes, and write a price table by weight and pincode, prefix or range, since Blue Dart has no rate service. On each shipment the Blue Dart Label panel generates a prepaid or cash on delivery waybill, proposing the order total for COD payment methods, saves Blue Dart's label PDF and stores the waybill as the tracking number, with scans shown in the tracking window. A pickup can be registered with the waybill. For example, a Mumbai seller can charge less for pincodes starting with 40.

Features

  • Blue Dart services at checkout for 6-digit Indian pincodes
  • Price table by service, pincode, prefix or range and weight band, validated on save
  • Pincode serviceability check; pincodes that are not serviceable do not see Blue Dart
  • Prepaid and cash on delivery waybills; the order total is proposed as the amount to collect for COD orders
  • Label PDF stored on the shipment and downloadable
  • One waybill per shipment: a repeated request does not book another
  • Waybill number added as the tracking number, with scan history in the tracking window
  • Separate admin permission for waybills
  • Mock, Sandbox and Production modes; dedicated debug log with credentials masked

Good to know

Requires a Blue Dart customer code and API credentials: consumer key and secret, login ID and licence key. Blue Dart has no rate service, so checkout prices are the ones you enter; the store's base currency should be INR. One piece per shipment, forward shipments only. This extension was verified in Mock mode only and has not been run against a live Blue Dart account; test with your sandbox credentials before going live.

Blue Dart Shipping: questions

Which Magento versions does Blue Dart Shipping support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Blue Dart Shipping cost?

$30 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Blue Dart Shipping?

With Composer: composer require modvanta/module-bluedart-shipping, then bin/magento setup:upgrade. We can also install and configure it on your store.
