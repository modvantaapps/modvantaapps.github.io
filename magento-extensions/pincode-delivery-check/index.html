What it does

Indian pincode serviceability: which PIN codes you deliver to, whether cash on delivery (COD) or prepaid is accepted there, and an honest estimated delivery date (EDD) on the product page, at checkout and on the order.

This tool tells Indian shoppers whether the store delivers to their PIN code, whether cash on delivery is accepted there, and when the order should arrive. The merchant imports a pincode table by CSV under Stores > Settings > Pincode Serviceability, with serviceable, COD and prepaid flags and delivery days; no national dataset is included. Product pages get a Check delivery box showing the delivery date and COD availability, or a plain message if unconfirmed. At checkout, invalid or unserviceable pincodes are rejected, COD or prepaid methods are hidden where not allowed, and the estimate appears under the shipping methods. The estimate is stored on the order and shown in the admin order view and order e-mails. It uses the order cut-off, handling days per product, transit days, weekly days off and holidays, all set by the merchant. Limiting COD to reliable areas is a typical use.

Features

  • Pincode table: pincode (6 digits, first digit 1-9), city, district, state (mapped to the Magento region of country IN), zone, serviceable, COD allowed, prepaid allowed
  • CSV import / export in Stores > Settings > Pincode Serviceability (Modvanta) (grid with filters, mass delete, sample download)
  • Estimated delivery date: computed in the store time zone
  • PDP widget "Check delivery": pincode input, remembers the last pincode in, shows the delivery date, city / state and COD availability
  • Checkout (Indian shipping addresses only)
  • GraphQL (not cached) and REST (anonymous)

Where you find it in the admin

  • Stores > Settings > Pincode Serviceability (Modvanta)

Pincode Delivery Check: questions

Which Magento versions does Pincode Delivery Check support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Pincode Delivery Check cost?

$25 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Pincode Delivery Check?

With Composer: composer require modvanta/module-pincode-delivery, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
