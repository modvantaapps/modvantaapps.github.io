What it does

Standards-based browser push notifications, sent directly from your server to the browser vendors' push services (Google FCM, Mozilla autopush, Microsoft WNS, Apple Web Push). No third-party SaaS, no SDK, no CDN script.

This extension sends browser push notifications from your own server to shoppers who opt in, through the Chrome, Firefox, Edge and Safari push services. On the storefront a small dismissible banner with "Notify me" and "No thanks" appears after a set delay, and the browser permission prompt opens only after the shopper clicks. Customers switch notifications on or off on a "Browser Notifications" page in My Account. Under Marketing > Web Push the merchant drafts, schedules or sends campaigns to all subscribers, customer groups or store views and reviews campaign statistics. Automatic pushes can go out when an order ships, its status changes or a wish list item drops in price. The Web Push Notifications section of Stores > Configuration sets the prompt title, text, delay, icon, message lifetime and retry limits, and cron sends queued messages. For example, a fashion store can announce a weekend sale.

Features

  • Browser push notifications sent directly from your server (VAPID, RFC 8291 encryption) to Chrome, Firefox, Edge and Safari push services; no third-party service or SDK
  • Soft opt-in prompt: the browser permission prompt only appears after the shopper clicks "Notify me"
  • "Browser Notifications" page in My Account to turn notifications on or off
  • Manual campaigns (Marketing > Web Push > Push Campaigns): draft, schedule or send now to all subscribers, customer groups or store views
  • Automatic notifications: order shipped, order status changes, wish list price drops and back in stock / price alerts (with the Modvanta Back In Stock extension)
  • Queue-based delivery with retries, removal of expired subscriptions and per-message de-duplication
  • Subscriber and campaign statistics, VAPID key management, GraphQL for headless storefronts
  • Test mode with a simulated browser to check delivery without a real browser

Where you find it in the admin

  • Marketing > Web Push > Push Campaigns
  • Marketing > Web Push > Subscribers
  • Marketing > Web Push > VAPID Keys
  • Marketing > Web Push > Settings

Good to know

This module supports compliance with consent and privacy rules for push messaging (GDPR / ePrivacy Art. 5(3) and 6, India DPDP Act 2023, CCPA/CPRA): permission is only requested after an explicit click, unsubscribing is one click in the browser or on the "Browser Notifications" page, and subscriptions are deleted on account deletion and privacy erasure. It does not certify compliance. Describe push subscriptions in your privacy notice.

Web Push Notifications: questions

Which Magento versions does Web Push Notifications support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Web Push Notifications cost?

$30 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Web Push Notifications?

With Composer: composer require modvanta/module-web-push, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
