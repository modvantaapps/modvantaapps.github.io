What it does

AI translation of store-view content (Content > AI Translator): products, categories, CMS pages and blocks and product attribute option labels are machine-translated from a source store view into target store views, land in a review queue and are only written to the store after a human approves them.

This tool machine-translates store-view content and holds every result for human review before the storefront changes. Under Content > AI Translator the merchant creates a job for products, categories, CMS pages and blocks or attribute option labels, picks source and target store views and fields, and sees a cost estimate first. Providers are DeepL, an OpenAI-compatible API, Anthropic, or an offline test provider. HTML, widgets and links are protected, and a glossary forces set translations or keeps brand names untranslated. Results land in a Review Queue with a side-by-side editor; approved items are published to the target store view, and translated CMS content goes into a store-specific copy so other views stay untouched. Existing translations are skipped unless overwrite is chosen. Merchants set default fields, tone instructions, formality and rate limits. A store adding a French store view is a typical case.

Features

  • OpenAI-compatible
  • Anthropic and DeepL providers
  • HTML / Page Builder / directive safe placeholders
  • Cost estimate
  • Rate-limited queue jobs
  • Human review queue with side-by-side diff
  • Publish per store view and EU AI Act transparency registration

Where you find it in the admin

  • Content > AI Translator > Translation Jobs
  • Content > AI Translator > Review Queue
  • Content > AI Translator > Glossary
  • Content > AI Translator > Configuration

AI Translator With Glossary: questions

Which Magento versions does AI Translator With Glossary support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does AI Translator With Glossary cost?

$30 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install AI Translator With Glossary?

With Composer: composer require modvanta/module-ai-translator, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
