What it does

India GST e-way bills. Builds Part A and Part B from an invoice (and its shipment), checks the threshold, and generates through a mock or the NIC e-way bill API (via a GSP), or by IRN when the Modvanta Gst E Invoice extension registered the invoice. It also exports the EWB portal bulk-upload JSON, cancels bills within 24 hours, updates Part B (vehicle), prints a PDF summary and can auto-generate on shipment.

This tool prepares GST e-way bills for Indian shipments from the invoice and shipment. Invoice and shipment pages get a Generate E-way Bill button with Part A and Part B prefilled, and bills can also be created automatically when a shipment is saved above the threshold. Generation works through an offline mock, by IRN when the GST e-invoice add-on has registered the invoice, or through an NIC API connector via a GSP that must first be verified in the GSP sandbox; the portal bulk-upload JSON can always be downloaded. Sales > Operations > E-way Bills shows status, validity, vehicle and value, with cancel, vehicle updates and PDF. Merchants set thresholds per state, the default transporter, courier IDs, mode, distance and dispatch address. Sellers of high-value consignments are typical users.

Features

  • Part A/Part B from invoices and shipments
  • Configurable consignment thresholds
  • Validity per Rule 138(10)
  • Mock and NIC (via GSP) providers
  • EWB by IRN with the Modvanta Gst E Invoice extension
  • EWB portal bulk-upload JSON
  • Cancel within 24 hours
  • Vehicle (Part B) updates
  • Admin grid
  • Auto-generation on shipment and CLI

Where you find it in the admin

  • Sales > Operations > E-way Bills

Good to know

This module supports compliance with section 68 CGST Act and rule 138 CGST Rules 2017. It does not certify compliance and is not tax advice. Check the current Central and State notifications with your tax advisor.

India GST EWay Bill: questions

Which Magento versions does India GST EWay Bill support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does India GST EWay Bill cost?

$25 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install India GST EWay Bill?

With Composer: composer require modvanta/module-eway-bill, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
