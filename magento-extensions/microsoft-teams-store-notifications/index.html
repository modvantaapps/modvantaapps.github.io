What it does

Posts what happens in your store to Microsoft Teams as Adaptive Cards: new orders with items and totals, status changes, cancellations, failed checkouts, invoices, shipments with tracking, refunds, new customers, reviews awaiting approval, low stock, contact form messages and a daily sales summary. It uses Teams Workflows webhooks, the method Microsoft provides now that Office 365 connectors are retired. Cards are prepared by cron, so checkout is never slowed down.

Staff see store activity as cards in their Teams channels or chats, each showing the key facts, the ordered items and a button that opens the record in your admin. Twelve events are covered: new orders, status changes, cancellations, failed checkouts, invoices, shipments with tracking, refunds, new customers, reviews awaiting approval, low stock, contact form messages and a daily sales summary. Under System > Teams Notifications > Destinations you add one webhook per channel and choose its events and store views. Events are queued and turned into cards by cron, with retries and a delivery log offering View and Resend. In Stores > Configuration you set item rows per card, the low stock threshold and the summary hour, and mock mode stores cards without sending them. The storefront is unchanged. For example, orders can go to a sales channel and low stock to the warehouse channel.

Features

  • Twelve events, each rendered as an Adaptive Card with facts, an item table and a button to the admin record
  • Any number of destinations, each with its own events and store views
  • Webhook address stored encrypted and only ever shown masked
  • Retired Office 365 connector addresses are refused with an explanation
  • Long orders are shortened to stay under the Teams size limit
  • Automatic retries for throttling, server errors and unreachable hosts; refused requests are marked Failed with a plain reason
  • Delivery log with the exact card and request body, plus Resend
  • Send Test Card per destination, with a guard against double clicks
  • Mock mode to try everything without a Microsoft account
  • Separate permissions for view, save, delete, test card, resend and settings

Good to know

Requires Microsoft Teams with the Workflows app, and the store cron. Only the workflow type where anyone with the address can post is supported. Cards validate against the Adaptive Card 1.4 schema; the extension was verified in Mock mode and against Microsoft's error answers, so send a test card after switching to Live.

Microsoft Teams Store Notifications: questions

Which Magento versions does Microsoft Teams Store Notifications support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Microsoft Teams Store Notifications cost?

$30 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Microsoft Teams Store Notifications?

With Composer: composer require modvanta/module-teams-notifications, then bin/magento setup:upgrade. We can also install and configure it on your store.
