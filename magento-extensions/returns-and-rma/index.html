What it does

Give customers a clear way to ask for a return, and your team one place to handle it. Customers choose the items, a reason and what they would like; you approve, reject or close the request.

This extension gives customers a clear way to ask for a return and your team one place to handle it. Customers use a Request Return button on the order view in My Account, or a guest lookup page, to choose items and quantities, a reason, the resolution they want and photos, and follow it under My Returns. Eligibility rules check the return window from the last shipment, non-returnable products, excluded categories and a limit per customer. Under Sales > Operations > Returns staff see each request with photos, a fraud score, an optional AI triage suggestion and buttons to approve, reject, mark received, refund through a credit memo, mark as exchanged or close. Requests can be approved automatically when confidence is high and risk is low. In the configuration you set the rules, photo limits, fraud thresholds, AI provider and refund options. It suits apparel stores.

Features

  • Request Return from the order page, for customers and for guests
  • Items, quantity, condition, reason and preferred resolution: refund, exchange or store credit
  • Photos attached to the request
  • Messages between customer and store
  • Rule-based fraud score for every request
  • Automatic approval for low-risk requests
  • Admin grid and request page with approve, reject and close
  • Credit memo created offline from an approved return
  • Optional assisted triage that suggests a category and resolution, using a built-in rule-based provider or an AI provider you configure
  • My Returns in the customer account
  • GraphQL support and command-line tools

Where you find it in the admin

  • Sales > Operations > Returns

Good to know

The AI providers are optional and are not used unless you enter your own API key.

Returns & RMA: questions

Which Magento versions does Returns & RMA support?

Magento Open Source and Adobe Commerce 2.4 (developed and tested on 2.4.9), with PHP 8.1 to 8.5 and Luma-based themes. If your store runs Hyva or a headless front end, tell us first and we check it before you buy.

How much does Returns & RMA cost?

$50 as a one-time payment for one Magento installation. You get the full source code and a PDF user guide. There is no yearly fee.

How do I install Returns & RMA?

With Composer: composer require modvanta/module-returns, then bin/magento setup:upgrade. It pulls in the free Modvanta Core package automatically. We can also install and configure it on your store.
